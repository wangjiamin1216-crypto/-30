# 买家查看指标商品列表页页面协议

## 1. 页面目标

买家查看指标商品列表页用于承接买家“按指标找货”的核心场景，帮助买家基于指标组合、指标容差、价格、可售吨位和交付条件快速找到可采购的已上架指标商品。

本页面的核心目标包括：

- 帮助买家快速查看当前可采购的指标商品。
- 帮助买家基于核心指标进行筛选、排序和初步判断。
- 帮助买家比较相近指标商品的关键差异。
- 帮助买家从列表直接进入指标商品详情页。
- 帮助买家基于已上架指标商品发起基础询价或议价沟通。
- 帮助平台沉淀买家关注指标、查看行为和议价意向数据。

本页面不承担：

- 商品详情完整解释。
- 完整指标对比分析。
- 完整企业沟通流程。
- 订单、合同、履约、物流、金融流程。
- 卖家指标商品状态流转。

---

## 2. 页面核心原则

### 2.1 指标优先原则

- 页面信息组织必须优先展示指标，不以商品图片、商品名称或营销描述作为主要判断依据。
- 核心指标必须优先于普通指标展示。
- 指标值、指标单位和指标容差必须形成可理解的结构。
- 买家筛选条件必须围绕指标展开，而不是围绕传统商品分类堆叠。

### 2.2 可交易状态原则

- 页面只展示 `当前状态 = 已上架` 的指标商品。
- 草稿、待审核、审核驳回、已下架的指标商品不得进入列表结果。
- 询价、议价入口只对允许询价或允许议价的已上架指标商品开放。
- 买家侧不得通过 URL、缓存或历史数据绕过指标商品状态规则。

### 2.3 采购判断效率原则

- 买家应能在列表层完成初步采购判断。
- 列表必须展示支持采购判断的核心信息，包括核心指标、报价、可售吨位、最小起售数量、交付区域和交付方式。
- 页面应支持买家快速收敛结果，而不是让买家逐个进入详情页判断。

### 2.4 结构化沟通原则

- 列表页发起沟通时，必须携带指标商品 ID、买家企业 ID、卖家企业 ID 和来源页面。
- 沟通入口应引导买家围绕指标、吨位、价格和交付条件表达诉求。
- 列表页只提供沟通入口，不定义完整沟通状态机。

### 2.5 风控审计原则

- 查看列表、筛选、排序、查看详情、发起沟通、加入比较等关键行为应记录行为日志。
- 发起沟通前必须校验指标商品最新状态、询价/议价入口、价格有效期和状态版本号。
- 页面展示数据必须以服务端最新可见数据为准。

| 列表结果模块 | 展示符合条件的已上架指标商品 | 指标商品基础字段、指标字段、经营字段、沟通字段 | 查看详情、发起沟通、加入比较 |

| 比较入口模块 | 支持买家把相近货源加入比较 | 指标商品 ID、核心指标、报价、可售吨位、交付条件 | 加入比较、进入比较页 |
| 沟通入口模块 | 支持买家基于已上架商品发起询价或议价 | 是否允许询价、是否允许议价、IM 入口标识 | 发起沟通、进入企业沟通中心 |

## 4. 页面核心行为

### 4.1 搜索

| 行为 | 规则 |
| --- | --- |
| 关键词搜索 | 支持按商品名称、品类、生产区域、交付区域等基础信息搜索 |
| 指标关键词搜索 | 支持按发热量、硫分、水分、灰分等指标名称或指标口径搜索 |
| 搜索结果范围 | 仅返回已上架且买家有权限查看的指标商品 |
| 搜索日志 | 记录买家企业 ID、搜索关键词、筛选条件、搜索时间 |

### 4.2 指标筛选

| 行为 | 规则 |
| --- | --- |
| 按指标值筛选 | 支持按指标名称、指标值、指标单位筛选 |
| 按指标容差筛选 | 支持按买家可接受的指标上下限筛选 |
| 多指标组合筛选 | 支持多个核心指标组合筛选 |
| 筛选结果校验 | 筛选结果仍必须满足 `当前状态 = 已上架` |

### 4.3 经营条件筛选

| 行为 | 规则 |
| --- | --- |
| 按价格筛选 | 基于报价金额和价格单位筛选 |
| 按吨位筛选 | 基于可售吨位和最小起售数量筛选 |
| 按交付筛选 | 基于生产区域、交付区域、交付方式筛选 |
| 按价格有效期筛选 | 价格有效期失效的商品应降低推荐优先级或提示需重新确认 |

### 4.4 排序

| 排序方式 | 排序依据 |
| --- | --- |
| 指标匹配优先 | 买家筛选指标与指标商品核心指标的匹配程度 |
| 价格优先 | 报价金额、价格单位和历史成交参考 |
| 可售吨位优先 | 可售吨位、最小起售数量 |
| 更新时间优先 | 最近修改时间或经营信息更新时间 |
| 交付匹配优先 | 交付区域、交付方式与买家采购意图匹配程度 |

### 4.5 查看详情

| 行为 | 规则 |
| --- | --- |
| 查看详情 | 跳转至买家指标商品详情页 |
| 传递对象 | 指标商品 ID、当前筛选条件 |
| 前置校验 | 指标商品必须仍为已上架且买家有查看权限 |
| 行为日志 | 记录查看详情行为，用于商品被查看次数和买家关注指标沉淀 |

### 4.6 加入比较

| 行为 | 规则 |
| --- | --- |
| 加入比较 | 将指标商品加入买家当前比较集合 |
| 比较对象 | 指标商品 ID、核心指标、报价、可售吨位、交付条件 |
| 比较边界 | 列表页只提供加入比较入口，不承载完整比较分析 |
| 跳转目标 | 买家指标比较页 |

### 4.7 发起沟通

| 行为 | 规则 |
| --- | --- |
| 发起询价 | 当 `是否允许询价 = 开启` 时可发起 |
| 发起议价 | 当 `是否允许议价 = 开启` 时可发起 |
| 前置校验 | 校验当前状态、状态版本号、价格有效期、可售吨位和最小起售数量 |
| 传递对象 | 指标商品 ID、买家企业 ID、卖家企业 ID、来源页面 |
| 跳转目标 | 企业沟通中心买家会话页 |
| 协议边界 | 不定义协商状态机，不定义报价单、订单、合同流程 |

## 5. 页面布局

本节只定义信息区域与业务职责，不定义 UI 视觉、样式和组件细节。

### 5.1 页面信息区域

| 区域 | 区域目标 | 承载内容 |
| --- | --- | --- |
| 页面入口区 | 明确当前页面服务买家找货场景 | 页面名称、当前买家企业上下文、返回或导航入口 |
| 搜索筛选区 | 帮助买家输入采购条件并缩小范围 | 搜索条件、指标筛选、经营条件筛选、交付条件筛选 |
| 结果概览区 | 帮助买家理解当前结果规模和筛选效果 | 结果数量、当前筛选摘要、排序方式 |
| 指标商品列表区 | 展示符合条件的已上架指标商品 | 指标商品摘要、核心指标、价格、吨位、交付条件、操作入口 |
| 比较暂存区 | 暂存买家选中的待比较货源 | 已加入比较的指标商品摘要 |
| 沟通入口区 | 提供从列表进入企业沟通中心的路径 | 发起询价、发起议价、进入会话 |

### 5.2 信息优先级

| 优先级 | 信息 |
| --- | --- |
| P0 | 核心指标、指标值、指标单位、指标容差、当前报价、可售吨位、最小起售数量、交付区域、是否允许询价/议价 |
| P1 | 商品名称、商品品类、卖家企业、生产区域、交付方式、价格有效期、历史最高成交价、历史最低成交价 |
| P2 | 商品图片、商品说明、附件摘要、被查看次数、商品售卖次数、商品售卖总量 |

### 5.3 列表项信息结构

每个指标商品列表项应至少承载：

- 指标商品 ID。
- 商品名称。
- 商品品类。
- 卖家企业 ID 或卖家企业摘要。
- 核心指标列表。
- 指标值、指标单位、指标容差。
- 报价方式、报价金额、价格单位。
- 价格有效期。
- 可售吨位。
- 最小起售数量。
- 生产区域。
- 交付区域。
- 交付方式。
- 是否允许询价。
- 是否允许议价。
- IM 入口标识。

## 6. 空状态

| 空状态 | 触发条件 | 页面处理 |
| --- | --- | --- |
| 无可见指标商品 | 当前买家权限范围内无已上架指标商品 | 提示暂无可采购指标商品，不展示非已上架数据 |
| 筛选无结果 | 买家筛选条件过窄或无匹配指标商品 | 保留筛选条件，提示调整指标范围、价格区间或交付条件 |
| 搜索无结果 | 关键词无匹配结果 | 提示更换关键词或使用指标筛选 |
| 比较集合为空 | 买家尚未加入任何商品比较 | 提示可从列表加入相近指标商品进行比较 |
| 沟通入口不可用 | 商品不允许询价或议价 | 不开放发起沟通入口，提示当前商品暂不支持新增沟通 |

空状态不得：

- 展示草稿、待审核、审核驳回、已下架商品作为替代结果。
- 引导买家绕过商品状态规则联系卖家。
- 自动生成采购意图或自动发起沟通。

## 7. 异常状态

| 异常状态 | 触发条件 | 处理规则 |
| --- | --- | --- |
| 商品状态变化 | 买家查看列表后，商品从已上架变为已下架或待审核 | 列表刷新后移除该商品；操作时校验失败则提示商品已不可交易 |
| 商品版本过期 | 买家基于旧列表数据发起沟通或查看详情 | 服务端校验状态版本号，要求刷新最新数据 |
| 价格有效期失效 | 当前时间超过价格有效期 | 保留商品可见性，但发起议价前提示价格需重新确认 |
| 可售吨位不足 | 可售吨位小于买家筛选吨位或最小起售要求 | 列表可提示吨位不满足；发起沟通前必须二次校验 |
| 权限异常 | 买家无权查看某指标商品或卖家企业数据 | 拒绝查看和操作，记录越权访问日志 |
| 筛选条件非法 | 指标容差下限大于上限、价格区间非法、吨位为负数 | 阻断查询并提示修正条件 |
| 并发冲突 | 商品在买家操作期间被卖家修改关键经营字段 | 以服务端最新版本为准，提示买家刷新或重新确认 |
| 数据加载失败 | 网络、接口或服务异常 | 保留当前页面上下文，提示重试，不展示错误数据 |

异常处理原则：

- 异常不得新增买家侧商品状态。
- 异常不得绕过卖家侧指标商品主状态。
- 阻断类异常必须记录异常日志。
- 与状态、价格、可售吨位、权限相关的异常必须以服务端校验结果为准。

## 8. 与字段协议的关系

### 8.1 读取字段范围

买家查看指标商品列表页读取字段协议中的以下字段：

| 字段层级 | 列表页读取字段 | 页面用途 |
| --- | --- | --- |
| 基础字段 | 指标商品 ID、卖家企业 ID、商品名称、商品品类、商品图片、商品说明、附件 | 辅助识别、进入详情、查看检测材料摘要 |
| 指标字段 | 指标组、指标名称、指标值、指标单位、指标容差下限、指标容差上限、指标说明、核心指标标记、指标排序 | 支持筛选、排序、列表摘要和采购判断 |
| 经营字段 | 报价方式、报价金额、价格单位、价格有效期、历史最高成交价、历史最低成交价、库存数量、可售吨位、生产区域、交付区域、交易方式、交付方式、最小起售数量、经营备注 | 支持价格、吨位、交付和交易条件判断 |
| 状态字段 | 当前状态、状态版本号、最近修改时间、下架时间 | 控制可见性、并发校验和操作前校验 |
| 沟通字段 | 是否允许询价、是否允许议价、最新沟通 ID、最新沟通时间、最新沟通内容、IM 入口标识 | 控制沟通入口和进入企业沟通中心 |

### 8.2 字段使用规则

- `当前状态` 只用于控制买家侧可见性和操作权限，不允许买家侧修改。
- `状态版本号` 用于查看详情、发起沟通、加入比较等行为的并发校验。
- `指标组`、`指标值`、`指标单位`、`指标容差` 是页面核心展示与筛选依据。
- `报价金额`、`价格有效期`、`可售吨位`、`最小起售数量` 是买家采购判断和发起沟通前校验依据。
- `是否允许询价` 和 `是否允许议价` 由指标商品状态决定，买家侧不得自行覆盖。
- `最新沟通 ID` 和 `IM 入口标识` 只作为进入企业沟通中心的入口，不定义沟通状态机。

### 8.3 字段写入边界

本页面不直接修改指标商品字段。

本页面允许产生以下行为数据：

- 买家搜索日志。
- 买家筛选日志。
- 买家查看详情日志。
- 买家加入比较记录。
- 买家发起沟通入口记录。
- 买家关注指标统计数据。

上述行为数据不得反向修改指标商品主状态、核心指标、报价、库存或可售吨位。

## 9. MVP边界

### 9.1 当前 MVP 必须支持

- 查看已上架指标商品列表。
- 按商品品类、核心指标、指标值、指标容差筛选。
- 按报价金额、可售吨位、交付区域、交付方式筛选。
- 按指标匹配、价格、可售吨位、更新时间排序。
- 查看指标商品摘要。
- 跳转至买家指标商品详情页。
- 将指标商品加入比较集合。
- 从列表页进入企业沟通中心发起基础询价或议价。
- 操作前校验当前状态、状态版本号、价格有效期和可售吨位。
- 记录搜索、筛选、查看详情、加入比较、发起沟通等行为日志。

### 9.2 当前 MVP 不做

- 不做完整指标比较页的分析规则。
- 不做完整企业沟通中心结构。
- 不做协商状态机。
- 不做库存状态机。
- 不做卖家工作台状态机。
- 不做订单确认流程。
- 不做合同、物流、履约、售后、金融流程。
- 不做 AI 自动推荐采购方案。
- 不做跨商品组合采购。
- 不做自动生成采购意向。
- 不做未上架商品的买家侧预览。

### 9.3 后续可扩展方向

- 支持基于买家采购意图的指标商品推荐。
- 支持多商品组合比较。
- 支持指标价格趋势参考。
- 支持买家企业常用指标模板。
- 支持同类指标商品价格区间分析。
- 支持指标关注数据反哺卖家经营建议。

## 10. 协议结论

买家查看指标商品列表页是买家侧“看指标、比指标、聊指标”的入口页面。

该页面必须围绕指标筛选和采购判断组织信息，只展示已上架指标商品，只开放符合状态规则的询价和议价入口。页面本身不定义任何新的状态机，不修改指标商品主字段，只通过搜索、筛选、查看、比较和沟通入口推动买家进入后续详情和企业沟通场景。
