# 买家侧核心场景协议

## 0. 协议边界

本协议仅定义买家侧围绕指标商品的核心场景、对象、页面承接和与卖家侧指标商品状态的关系。

---

## 1. 买家场景目标

买家侧核心目标不是“浏览商品”，而是围绕指标完成采购判断与交易意向推进。

| 场景 | 目标 |
| --- | --- |
| 查看指标商品列表 | 帮助买家基于指标组合、指标容差、价格、可售吨位、交付条件快速筛选可采购货源 |
| 查看指标商品详情 | 帮助买家理解单个指标商品是否满足采购要求，并确认关键指标、报价、交付和可沟通空间 |
| 发起议价沟通 | 帮助买家围绕指标、吨位、价格、交付条件提出结构化议价诉求 |
| 围绕指标推进交易意向 | 帮助买卖双方在企业沟通中心围绕指标商品持续确认需求、报价和交易意向 |

---

## 2. 买家角色意图

| 买家角色意图 | 说明 | 依赖信息 |
| --- | --- | --- |
| 按指标找货 | 买家优先按发热量、硫分、水分、灰分等指标筛选，而不是按商品名称浏览 | 指标名称、指标值、指标单位、指标容差 |
| 判断采购匹配度 | 买家需要快速判断商品是否满足自身采购标准 | 核心指标、容差范围、交付区域、最小起售数量 |
| 比较相近货源 | 买家需要比较多个指标相近商品的价格、库存、交付条件 | 报价金额、历史成交价、可售吨位、交付方式 |
| 发起议价 | 买家希望基于采购吨位、目标价格、指标容差提出议价诉求 | 是否允许议价、报价方式、价格有效期、最小起售数量 |
| 围绕指标沟通 | 买家希望沟通内容聚焦指标、检测口径、容差、交付和价格，而不是普通聊天 | 最新沟通 ID、IM 入口标识、指标商品 ID |
| 推进交易意向 | 买家希望在指标基本确认后沉淀交易意向，便于后续订单、合同、履约承接 | 指标商品、买家企业、卖家企业、沟通记录、议价诉求 |

---

## 3. 核心业务对象

### 3.1 指标商品

买家侧读取卖家侧已上架的指标商品。

| 对象属性 | 买家侧用途 |
| --- | --- |
| 指标商品 ID | 关联列表、详情、沟通、议价、交易意向 |
| 卖家企业 ID | 识别供应方，建立企业沟通关系 |
| 商品名称 | 辅助识别，不高于指标优先级 |
| 商品品类 | 支持分类筛选 |
| 指标组 | 买家判断采购匹配度的核心 |
| 核心指标标记 | 决定列表和详情的优先展示口径 |
| 指标值、单位、容差 | 支持筛选、比较、议价和沟通 |
| 报价方式、报价金额、价格单位 | 支持价格判断和议价 |
| 价格有效期 | 判断报价是否仍可作为沟通依据 |
| 可售吨位、最小起售数量 | 判断是否满足采购量要求 |
| 生产区域、交付区域、交付方式 | 判断交付可行性 |
| 附件、检测报告 | 支持买家验证指标真实性 |
| 当前状态 | 决定买家是否可见、是否可发起议价 |

### 3.2 买家采购意图

买家采购意图是买家围绕某类指标商品形成的需求表达，不定义独立状态机。

| 字段 | 说明 |
| --- | --- |
| 买家企业 ID | 发起采购意图的企业 |
| 目标品类 | 例如动力煤、焦煤、无烟煤 |
| 目标指标组合 | 买家期望的指标条件 |
| 指标容差要求 | 买家可接受的指标上下限 |
| 目标采购吨位 | 买家预计采购数量 |
| 目标价格或价格区间 | 买家期望议价区间 |
| 目标交付区域 | 买家期望收货或交付区域 |
| 期望交付时间 | 买家期望交付周期 |
| 备注说明 | 补充检测、扣罚、发运、结算等诉求 |

### 3.3 指标议价诉求

指标议价诉求是买家发起沟通时的结构化内容，不定义协商状态机。

| 字段 | 说明 |
| --- | --- |
| 指标商品 ID | 议价关联的商品 |
| 买家企业 ID | 发起议价企业 |
| 卖家企业 ID | 接收议价企业 |
| 议价指标项 | 买家关注或要求确认的指标 |
| 目标采购吨位 | 本次议价对应数量 |
| 买家期望价格 | 买家提出的价格 |
| 指标容差诉求 | 对发热量、硫分、水分等指标的容差要求 |
| 交付诉求 | 对交付区域、交付方式、交付周期的要求 |
| 附加条款诉求 | 检测报告、扣罚规则、批次确认等要求 |
| 来源页面 | 列表页、详情页或企业沟通中心 |

### 3.4 企业沟通会话

企业沟通会话用于承载买卖双方围绕指标商品的沟通，不定义完整 IM 状态机。

| 字段 | 说明 |
| --- | --- |
| 会话 ID | 沟通唯一标识 |
| 指标商品 ID | 沟通关联的指标商品 |
| 买家企业 ID | 买方企业 |
| 卖家企业 ID | 卖方企业 |
| 最新沟通时间 | 用于双方工作台提醒 |
| 最新沟通内容 | 用于双方快速理解上下文 |
| IM 入口标识 | 进入企业沟通中心的入口 |
| 结构化沟通内容 | 指标咨询、议价诉求、卖家回复、交易意向摘要 |

### 3.5 交易意向记录

交易意向记录用于沉淀双方已初步确认的采购方向，不定义订单、合同或履约流程。

| 字段 | 说明 |
| --- | --- |
| 意向 ID | 交易意向唯一标识 |
| 指标商品 ID | 来源指标商品 |
| 买家企业 ID | 买方企业 |
| 卖家企业 ID | 卖方企业 |
| 确认指标组合 | 双方当前认可的指标口径 |
| 意向吨位 | 当前沟通形成的采购数量 |
| 意向价格 | 当前沟通形成的价格口径 |
| 交付条件摘要 | 当前确认的交付区域、方式、周期 |
| 形成来源 | 由企业沟通中心沉淀 |
| 后续承接 | 可被订单、合同等后续业务域引用 |

## 4. 核心页面清单

| 页面 | 页面目标 | 承接对象 | 主要业务行为 |
| --- | --- | --- | --- |
| 买家指标商品列表页 | 让买家基于指标组合快速查找可采购货源 | 指标商品、买家采购意图 | 搜索、筛选、排序、查看详情、加入比较、发起沟通入口 |
| 买家指标商品详情页 | 让买家完整理解单个指标商品的指标、价格、吨位和交付条件 | 指标商品 | 查看核心指标、查看完整指标、查看附件、发起议价沟通 |
| 买家指标比较页 | 让买家对比多个相近指标商品的差异 | 指标商品集合、买家采购意图 | 对比指标、价格、可售吨位、交付条件 |
| 企业沟通中心买家会话页 | 让买卖双方围绕指标商品进行结构化沟通 | 企业沟通会话、指标议价诉求 | 发送指标咨询、发起议价、确认沟通结论、沉淀交易意向 |
| 交易意向确认页 | 汇总双方围绕指标商品形成的初步意向 | 交易意向记录 | 查看意向摘要、确认指标口径、承接后续订单域 |

## 5. 页面之间的跳转关系

| 起点 | 触发行为 | 目标页面 | 传递对象 |
| --- | --- | --- | --- |
| 买家指标商品列表页 | 查看详情 | 买家指标商品详情页 | 指标商品 ID |
| 买家指标商品列表页 | 加入比较 | 买家指标比较页 | 指标商品 ID 列表 |
| 买家指标商品列表页 | 发起沟通 | 企业沟通中心买家会话页 | 指标商品 ID、买家企业 ID、卖家企业 ID |
| 买家指标商品详情页 | 返回列表 | 买家指标商品列表页 | 原筛选条件 |
| 买家指标商品详情页 | 加入比较 | 买家指标比较页 | 指标商品 ID |
| 买家指标商品详情页 | 发起议价 | 企业沟通中心买家会话页 | 指标商品 ID、议价诉求草稿 |
| 买家指标比较页 | 查看某商品详情 | 买家指标商品详情页 | 指标商品 ID |
| 买家指标比较页 | 选择商品发起议价 | 企业沟通中心买家会话页 | 指标商品 ID、比较结论 |
| 企业沟通中心买家会话页 | 查看商品详情 | 买家指标商品详情页 | 指标商品 ID |
| 企业沟通中心买家会话页 | 形成交易意向 | 交易意向确认页 | 会话 ID、指标商品 ID、交易意向摘要 |
| 交易意向确认页 | 回到沟通 | 企业沟通中心买家会话页 | 会话 ID |
| 交易意向确认页 | 查看商品详情 | 买家指标商品详情页 | 指标商品 ID |

## 6. 与卖家侧指标商品状态的关系

买家侧不定义卖家工作台状态机，只消费卖家侧指标商品主状态，并根据状态决定可见性和可操作性。

| 卖家侧指标商品状态 | 买家是否可搜索 | 买家是否可查看详情 | 买家是否可发起询价/议价 | 买家侧处理规则 |
| --- | --- | --- | --- | --- |
| 草稿 | 否 | 否 | 否 | 不进入买家列表、推荐、详情和沟通链路 |
| 待审核 | 否 | 否 | 否 | 不对买家展示，不允许绕过审核查看 |
| 审核驳回 | 否 | 否 | 否 | 不对买家展示，不允许发起任何交易意向 |
| 已上架 | 是 | 是 | 是 | 买家可查看列表、详情，可发起询价、议价和企业沟通 |
| 已下架 | 否 | 原则上否；历史入口可追溯 | 否 | 不再开放新的询价、议价；历史沟通和交易记录可按权限追溯 |

### 6.1 买家侧读取规则

- 买家列表页只读取 `当前状态 = 已上架` 的指标商品。
- 买家详情页只允许打开 `当前状态 = 已上架` 的指标商品。
- 企业沟通入口只在 `是否允许询价 = 开启` 或 `是否允许议价 = 开启` 时开放。
- `是否允许询价` 和 `是否允许议价` 由卖家侧指标商品状态决定，买家侧不得自行覆盖。
- 买家侧不得通过 URL、缓存、历史记录绕过指标商品状态规则。

### 6.2 状态变化后的买家侧处理

| 状态变化 | 买家侧影响 |
| --- | --- |
| 待审核 -> 已上架 | 指标商品进入买家列表、搜索、详情和沟通链路 |
| 已上架 -> 已下架 | 指标商品从买家列表、搜索和新增沟通入口移除 |
| 已下架 -> 待审核 | 买家侧仍不可见，直到再次审核通过并已上架 |
| 已上架期间经营字段修改 | 买家侧展示最新报价、价格有效期、可售吨位、交付条件；影响买家决策的字段修改必须可审计 |

### 6.3 历史沟通处理

- 若买家已基于某指标商品产生历史沟通，商品下架后历史沟通可按权限查看。
- 商品下架后，不允许基于该指标商品继续发起新的询价或议价。
- 历史沟通不得反向恢复指标商品为已上架。
- 历史交易意向、历史沟通、历史订单、历史合同由对应业务域追溯，不改变指标商品主状态。

---

## 7. 风控与审计约束

| 风险点 | 约束规则 |
| --- | --- |
| 查看未上架商品 | 买家侧查询必须服务端过滤非已上架商品 |
| 已下架商品继续议价 | 发起议价前必须校验指标商品最新状态 |
| 价格或吨位过期 | 发起议价前必须校验价格有效期、可售吨位和状态版本号 |
| 并发变更 | 买家提交议价诉求时必须携带指标商品版本信息，服务端以最新版本校验 |
| 越权查看 | 买家只能查看对其开放的已上架指标商品和自身企业相关沟通 |
| 沟通内容失真 | 指标咨询、议价诉求、卖家回复和交易意向摘要必须关联指标商品 ID |
| 审计缺失 | 查看详情、发起沟通、发起议价、形成交易意向应记录行为日志 |

---

## 8. 协议结论

买家侧核心场景应围绕：

- 看指标：通过列表和详情理解指标商品
- 比指标：通过比较判断相近货源差异
- 聊指标：通过企业沟通中心围绕指标、吨位、价格、交付推进交易意向

买家侧只消费卖家侧指标商品状态，不定义卖家状态机、库存状态机或协商状态机。唯一可进入买家新增交易链路的卖家侧状态是：`已上架`。
