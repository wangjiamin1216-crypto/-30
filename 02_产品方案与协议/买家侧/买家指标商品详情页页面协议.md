# 买家指标商品详情页页面协议

## 1. 页面目标

买家指标商品详情页用于承接买家从列表页进入单个指标商品后的深度判断场景，帮助买家完整理解该指标商品是否满足采购要求，并围绕指标、吨位、价格、交付条件发起结构化议价沟通。

本页面核心目标包括：

- 帮助买家查看单个已上架指标商品的完整指标信息。
- 帮助买家确认核心指标、指标容差、检测口径和指标说明。
- 帮助买家判断当前报价、可售吨位、最小起售数量、交付条件是否满足采购要求。
- 帮助买家查看检测报告、规格书、资质材料等辅助证明。
- 帮助买家基于指标商品发起询价或议价沟通。
- 帮助买家将商品加入比较，返回列表或进入企业沟通中心。
- 帮助平台沉淀买家查看详情、关注指标、发起沟通等行为数据。

本页面不承担：

- 协商状态机定义。
- 库存状态机定义。
- 卖家指标商品状态流转。
- 订单、合同、物流、履约、金融完整流程。
- 卖家字段编辑。
- UI 视觉设计和代码实现。

## 2. 页面核心原则

### 2.1 指标优先原则

- 页面必须以指标商品的指标组为核心组织信息。
- 核心指标优先展示，普通指标补充展示。
- 指标值、指标单位、指标容差、指标说明必须同时具备可读性。
- 商品名称、商品图片和商品说明只作为辅助识别信息，不得高于指标信息优先级。

### 2.2 状态准入原则

- 页面只允许打开 `当前状态 = 已上架` 的指标商品详情。
- 草稿、待审核、审核驳回、已下架商品不得开放买家新增查看入口。
- 如买家通过历史链接访问非已上架商品，应按权限和业务规则提示不可查看或仅允许历史追溯。
- 询价、议价入口必须由 `是否允许询价`、`是否允许议价` 控制。

### 2.3 决策增强原则

- 页面除展示卖家发布字段外，应提供辅助买家判断的信息摘要。
- 决策增强信息不得替代卖家发布字段，不得自动修改指标商品。
- 决策增强信息应围绕指标匹配、价格合理性、吨位可用性、交付可行性、材料可信度展开。

### 2.4 结构化议价原则

- 发起议价必须关联指标商品 ID、买家企业 ID、卖家企业 ID 和状态版本号。
- 议价诉求应围绕指标项、采购吨位、期望价格、指标容差、交付条件和附加条款表达。
- 页面只提供发起议价入口和议价诉求草稿，不定义协商状态机。

### 2.5 只读与审计原则

- 买家不得修改卖家发布的指标商品字段。
- 买家的查看、加入比较、发起沟通、发起议价行为必须记录行为日志。
- 发起议价前必须校验最新状态、状态版本号、价格有效期、可售吨位和入口权限。

## 3. 买家需要看到的商品指标

### 3.1 核心指标

核心指标用于买家快速判断商品是否满足采购标准，应作为详情页 P0 信息。

| 指标信息 | 字段来源 | 买家判断用途 |
| --- | --- | --- |
| 核心指标标记 | 卖家发布的指标字段 | 判断哪些指标是卖家重点经营指标 |
| 指标名称 | 卖家发布的指标字段 | 明确发热量、全硫分、灰分、全水分等指标项 |
| 指标值 | 卖家发布的指标字段 | 判断是否满足采购标准 |
| 指标单位 | 卖家发布的指标字段 | 避免不同计量口径导致误判 |
| 指标容差下限 | 卖家发布的指标字段 | 判断买家可接受最低边界 |
| 指标容差上限 | 卖家发布的指标字段 | 判断买家可接受最高边界 |
| 指标说明 | 卖家发布的指标字段 | 理解检测口径、适用条件或特殊说明 |

煤炭品类详情页建议优先展示以下指标：

- 收到基低位发热量。
- 全硫分。
- 全水分。
- 灰分。
- 挥发分。
- 固定碳。
- 粒度。
- 灰熔点。
- 哈氏可磨指数。
- 检测口径说明。

说明：

- 不同商品品类可使用不同指标模板。
- 指标模板不改变字段协议，只决定详情页指标展示优先级。

### 3.2 普通指标

普通指标用于补充买家采购判断，应作为详情页 P1 信息。

| 指标信息 | 展示目的 |
| --- | --- |
| 非核心指标项 | 补充采购判断，避免买家只凭单一指标决策 |
| 指标排序 | 决定指标阅读顺序 |
| 指标说明 | 补充检测、交付或应用场景说明 |
| 附件关联 | 支持买家查看该指标是否有检测材料支撑 |

### 3.3 指标解释与风险提示

指标解释与风险提示属于决策增强信息，不修改卖家发布字段。

| 信息 | 作用 |
| --- | --- |
| 指标是否落入买家筛选范围 | 帮助买家判断匹配程度 |
| 指标是否接近容差边界 | 提醒买家发起议价或补充确认 |
| 指标说明是否缺失 | 提醒买家沟通时确认检测口径 |
| 检测附件是否存在 | 帮助买家判断指标可信度 |
| 指标与同类商品差异 | 支持买家进入比较或议价 |

## 4. 字段来源说明

| 字段层级 | 字段 | 页面用途 |

| 基础字段 | 指标商品 ID | 详情、沟通、议价、比较的主关联对象 |

| 基础字段 | 商品名称 | 辅助识别商品载体 |
| 基础字段 | 商品品类 | 辅助买家理解指标模板 |
| 基础字段 | 商品图片 | 辅助识别，不作为主决策依据 |
| 基础字段 | 商品说明 | 补充商品背景，不替代指标说明 |
| 基础字段 | 附件 | 查看规格书、检测报告、资质材料 |
| 指标字段 | 指标组 | 详情页核心展示对象 |
| 指标字段 | 指标名称 | 展示单项指标 |
| 指标字段 | 指标值 | 展示指标结果 |
| 指标字段 | 指标单位 | 展示指标计量单位 |
| 指标字段 | 指标容差下限 | 展示可接受最低边界 |
| 指标字段 | 指标容差上限 | 展示可接受最高边界 |
| 指标字段 | 指标说明 | 展示检测口径、适用条件 |
| 指标字段 | 核心指标标记 | 决定核心指标展示优先级 |
| 指标字段 | 指标排序 | 决定指标展示顺序 |
| 经营字段 | 报价方式 | 判断固定价、区间价或在线议价 |
| 经营字段 | 报价金额 | 支持价格判断和议价 |
| 经营字段 | 价格单位 | 明确价格计量单位 |
| 经营字段 | 价格有效期 | 判断报价是否仍可作为沟通依据 |
| 经营字段 | 历史最高成交价 | 辅助买家判断价格区间 |
| 经营字段 | 历史最低成交价 | 辅助买家判断价格区间 |
| 经营字段 | 库存数量 | 辅助判断供应能力 |
| 经营字段 | 可售吨位 | 判断是否满足采购量 |
| 经营字段 | 生产区域 | 判断货源所在地 |
| 经营字段 | 交付区域 | 判断交付可行性 |
| 经营字段 | 交易方式 | 判断交易基础条件 |
| 经营字段 | 交付方式 | 判断运输和交付路径 |
| 经营字段 | 最小起售数量 | 判断发起询价或议价门槛 |
| 经营字段 | 经营备注 | 查看卖家补充说明 |
| 状态字段 | 当前状态 | 控制买家可见性与操作入口 |
| 状态字段 | 状态版本号 | 用于并发和操作前校验 |
| 沟通字段 | 是否允许询价 | 控制询价入口 |
| 沟通字段 | 是否允许议价 | 控制议价入口 |
| 沟通字段 | 最新沟通 ID | 关联已有沟通上下文 |
| 沟通字段 | IM 入口标识 | 进入企业沟通中心 |

### 4.2 来自系统计算或统计的信息

以下信息用于增强买家决策，不属于买家可修改字段。

| 信息 | 来源 | 用途 |
| --- | --- | --- |
| 指标匹配度 | 买家筛选条件与指标商品字段计算 | 帮助买家判断匹配程度 |
| 同类指标价格参考 | 同类商品历史成交、报价或平台统计 | 帮助买家判断报价合理性 |
| 近 7 天成交区间 | 平台经营统计 | 支持议价参考 |
| 近 7 天成交均价 | 平台经营统计 | 支持价格判断 |
| 当前报价相对位置 | 当前报价与参考区间对比 | 提醒价格偏高、合理或偏低 |
| 可售吨位满足度 | 买家期望吨位与可售吨位计算 | 判断供应能力 |
| 交付匹配度 | 买家期望交付区域与商品交付条件计算 | 判断履约可行性 |
| 附件完整性提示 | 附件字段校验 | 判断检测报告和材料是否完整 |
| 买家近期关注指标 | 系统统计 | 帮助平台沉淀采购需求 |

### 4.3 来自买家上下文的信息

以下信息来自买家当前操作或采购意图，用于详情页判断和议价草稿生成。

| 信息 | 用途 |
| --- | --- |
| 买家企业 ID | 校验买家权限、关联沟通会话 |
| 原列表筛选条件 | 判断该商品为何进入当前详情 |
| 买家目标指标组合 | 与商品指标进行匹配 |
| 买家目标采购吨位 | 与可售吨位、最小起售数量校验 |
| 买家目标价格区间 | 生成议价参考 |
| 买家目标交付区域 | 判断交付可行性 |

## 5. 决策增强信息

决策增强信息用于帮助买家更快判断是否值得沟通或议价，不改变指标商品字段。

| 决策维度 | 增强信息 | 业务用途 |
| --- | --- | --- |
| 指标匹配 | 核心指标是否满足买家筛选条件 | 判断是否符合采购标准 |
| 指标容差 | 商品指标与容差边界的距离 | 判断是否需要在沟通中确认检测波动 |
| 价格判断 | 当前报价、历史最高成交价、历史最低成交价、近 7 天参考区间 | 判断是否具备议价空间 |
| 吨位判断 | 可售吨位、最小起售数量、买家目标采购吨位 | 判断是否可满足采购规模 |
| 交付判断 | 生产区域、交付区域、交付方式、交易方式 | 判断交付可行性 |
| 材料可信度 | 附件、检测报告、资质材料完整性 | 判断指标真实性与风险 |
| 沟通建议 | 建议优先确认的指标、价格、吨位、交付条款 | 帮助买家结构化发起议价 |

决策增强信息必须满足：

- 不替代卖家发布字段。
- 不自动修改指标商品字段。
- 不自动发起议价。
- 不形成独立状态机。
- 需要可追溯其计算来源或统计口径。

## 6. 页面核心模块

| 模块 | 模块目标 | 主要承接信息 | 主要行为 |
| --- | --- | --- | --- |
| 商品基础识别模块 | 辅助买家确认当前查看的商品载体 | 商品名称、商品品类、商品图片、卖家企业 ID | 返回列表、加入比较 |
| 核心指标模块 | 帮助买家优先判断核心采购指标 | 核心指标标记、指标名称、指标值、指标单位、指标容差 | 查看核心指标、进入议价 |
| 完整指标模块 | 帮助买家查看全部指标结构 | 指标组、指标排序、指标说明、附件关联 | 查看全部指标 |
| 指标说明与检测材料模块 | 帮助买家验证指标可信度 | 指标说明、附件、规格书、检测报告、资质材料 | 查看附件、记录查看行为 |
| 价格与吨位模块 | 帮助买家判断价格和供应能力 | 报价方式、报价金额、价格单位、价格有效期、可售吨位、最小起售数量 | 发起询价、发起议价 |
| 交付与交易条件模块 | 帮助买家判断交付可行性 | 生产区域、交付区域、交付方式、交易方式、经营备注 | 发起沟通确认 |
| 决策增强模块 | 辅助买家判断是否值得议价 | 指标匹配度、价格参考、交付匹配、材料完整性 | 查看建议、生成议价草稿 |
| 侧边操作区 | 承载高频操作入口 | 是否允许询价、是否允许议价、IM 入口标识、状态版本号 | 发起议价、发起询价、加入比较 |
| 底部操作区 | 承接页面流转和次级操作 | 列表筛选条件、指标商品 ID、会话 ID | 返回列表、查看比较、进入沟通中心 |

## 7. 页面核心行为

### 7.1 查看商品详情

| 行为 | 规则 |
| --- | --- |
| 查看详情 | 买家从列表页、比较页或沟通中心进入详情页 |
| 前置校验 | 指标商品必须为已上架，且买家具备查看权限 |
| 传递对象 | 指标商品 ID、来源页面、原筛选条件 |
| 行为日志 | 记录买家企业 ID、指标商品 ID、查看时间、来源页面 |

### 7.2 查看完整指标

| 行为 | 规则 |
| --- | --- |
| 查看核心指标 | 默认优先读取核心指标标记为真的指标 |
| 查看全部指标 | 展示指标组内全部指标，按指标排序展示 |
| 查看指标说明 | 展示卖家发布的检测口径、适用条件或说明 |
| 查看指标附件 | 打开规格书、检测报告或资质材料 |

### 7.3 加入比较

| 行为 | 规则 |
| --- | --- |
| 加入比较 | 将当前指标商品加入买家比较集合 |
| 传递对象 | 指标商品 ID、核心指标、报价、可售吨位、交付条件 |
| 前置校验 | 当前指标商品必须仍为已上架 |
| 页面边界 | 详情页只提供加入比较入口，不展开完整比较页规则 |

### 7.4 发起询价

| 行为 | 规则 |
| --- | --- |
| 发起询价 | 当 `是否允许询价 = 开启` 时可发起 |
| 询价内容 | 采购吨位、期望交付时间、交付区域、指标确认问题 |
| 前置校验 | 当前状态、状态版本号、可售吨位、最小起售数量 |
| 目标页面 | 企业沟通中心买家会话页 |

### 7.5 发起议价

| 行为 | 规则 |
| --- | --- |
| 发起议价 | 当 `是否允许议价 = 开启` 时可发起 |
| 议价内容 | 议价指标项、目标采购吨位、买家期望价格、指标容差诉求、交付诉求、附加条款诉求 |
| 前置校验 | 当前状态、状态版本号、价格有效期、可售吨位、最小起售数量、买家权限 |
| 传递对象 | 指标商品 ID、买家企业 ID、卖家企业 ID、议价诉求草稿、来源页面 |
| 目标页面 | 企业沟通中心买家会话页 |
| 边界 | 不定义议价状态机，不生成订单，不锁定库存 |

### 7.6 查看或进入既有沟通

| 行为 | 规则 |
| --- | --- |
| 进入沟通中心 | 当存在 IM 入口标识时，可进入对应企业沟通会话 |
| 查看最新沟通摘要 | 可读取最新沟通内容、最新沟通时间 |
| 处理边界 | 详情页只做入口，不定义完整 IM 产品结构 |

## 8. 不允许买家修改的字段

买家在详情页对指标商品主字段全部只读，不允许直接修改卖家发布的指标商品字段。

### 8.1 基础字段不允许修改

| 字段 | 规则 |
| --- | --- |
| 指标商品 ID | 买家不得修改 |
| 卖家企业 ID | 买家不得修改 |
| 商品名称 | 买家不得修改 |
| 商品品类 | 买家不得修改 |
| 商品图片 | 买家不得修改 |
| 商品说明 | 买家不得修改 |
| 附件 | 买家不得新增、删除或替换 |
| 创建人、创建时间、最近修改人、最近修改时间 | 买家不得修改 |

### 8.2 指标字段不允许修改

| 字段 | 规则 |
| --- | --- |
| 指标组 | 买家不得修改 |
| 指标名称 | 买家不得修改 |
| 指标值 | 买家不得修改 |
| 指标单位 | 买家不得修改 |
| 指标容差下限 | 买家不得修改 |
| 指标容差上限 | 买家不得修改 |
| 指标说明 | 买家不得修改 |
| 核心指标标记 | 买家不得修改 |
| 指标排序 | 买家不得修改 |

### 8.3 经营字段不允许修改

| 字段 | 规则 |
| --- | --- |
| 报价方式 | 买家不得修改 |

| 价格单位 | 买家不得修改 |

| 库存数量 | 买家不得修改 |
| 可售吨位 | 买家不得修改，只能在询价/议价中提出采购吨位 |
| 生产区域 | 买家不得修改 |
| 交付区域 | 买家不得修改，只能在议价诉求中提出目标交付区域 |
| 交易方式 | 买家不得修改 |
| 交付方式 | 买家不得修改，只能在沟通中确认或提出诉求 |
| 最小起售数量 | 买家不得修改 |
| 经营备注 | 买家不得修改 |

### 8.4 状态字段和沟通字段不允许修改

| 字段 | 规则 |
| --- | --- |
| 当前状态 | 买家不得修改 |
| 状态版本号 | 买家不得修改 |
| 审核结果、审核意见、驳回原因、下架原因 | 买家不得修改 |
| 是否允许询价 | 买家不得修改 |
| 是否允许议价 | 买家不得修改 |
| 最新沟通 ID、最新沟通时间、最新沟通内容、IM 入口标识 | 买家不得修改，只能通过实际沟通行为由系统生成 |

### 8.5 买家允许提交的信息

买家只能提交与自身行为相关的数据，不得反向修改指标商品。

| 买家可提交信息 | 用途 |
| --- | --- |
| 采购吨位 | 用于询价或议价诉求 |
| 期望价格 | 用于议价诉求 |
| 指标确认问题 | 用于企业沟通 |
| 指标容差诉求 | 用于议价沟通 |
| 交付诉求 | 用于议价沟通 |
| 附加条款诉求 | 用于沟通检测、扣罚、批次确认等事项 |
| 加入比较记录 | 用于买家比较集合 |
| 查看行为日志 | 用于行为审计和指标关注统计 |

## 9. 页面底部/侧边操作区设计

本节只定义操作区的信息承载和业务规则，不定义视觉样式。

### 9.1 侧边操作区

侧边操作区用于承载详情页高频决策动作，应在买家阅读指标和价格时保持易访问。

| 操作入口 | 出现条件 | 操作规则 |
| --- | --- | --- |
| 发起议价 | 当前状态为已上架，且是否允许议价为开启 | 发起前校验状态版本号、价格有效期、可售吨位、最小起售数量 |
| 发起询价 | 当前状态为已上架，且是否允许询价为开启 | 发起前校验状态版本号、可售吨位、最小起售数量 |
| 加入比较 | 当前状态为已上架，且买家具备查看权限 | 加入买家比较集合，不改变指标商品字段 |
| 进入沟通中心 | 存在 IM 入口标识或可创建会话 | 进入企业沟通中心买家会话页 |
| 查看价格参考 | 存在价格参考数据 | 展示决策增强信息，不修改报价 |
| 查看材料 | 存在附件、检测报告或资质材料 | 记录材料查看行为 |

侧边操作区应承载的关键信息：

- 当前报价。
- 价格单位。
- 价格有效期。
- 可售吨位。
- 最小起售数量。
- 是否允许询价。
- 是否允许议价。
- 议价前需要确认的风险提示。

侧边操作区不得：

- 允许买家直接修改报价。
- 允许买家直接锁定库存。
- 允许买家直接修改指标。
- 绕过企业沟通中心生成订单。

### 9.2 底部操作区

底部操作区用于承接页面流转和次级操作。

| 操作入口 | 目标页面或结果 | 传递对象 |
| --- | --- | --- |
| 返回列表 | 买家指标商品列表页 | 原筛选条件、来源页面 |
| 查看比较 | 买家指标比较页 | 已加入比较的指标商品 ID 列表 |
| 查看企业沟通 | 企业沟通中心买家会话页 | 会话 ID、指标商品 ID |
| 查看交易意向 | 交易意向确认页 | 意向 ID 或会话 ID |

底部操作区应遵循：

- 不重复承载过多高频议价动作，议价和询价优先放在侧边操作区。
- 主要承接跨页面流转。
- 保留买家原列表筛选上下文。
- 不承载卖家编辑、审核、下架等动作。

## 11. 空状态

| 空状态 | 触发条件 | 页面处理 |
| --- | --- | --- |
| 商品不存在 | 指标商品 ID 无效或已被删除 | 提示商品不存在，不展示伪造数据 |
| 商品不可见 | 商品非已上架或买家无权限查看 | 提示商品当前不可查看或已不可交易 |
| 指标为空 | 指标组缺失或数据异常 | 阻断详情展示，记录异常 |
| 附件为空 | 卖家未上传附件或检测材料 | 提示暂无材料，建议沟通确认检测口径 |
| 价格为空 | 报价方式支持在线询价但无固定报价 | 提示需发起询价确认价格 |
| 价格参考为空 | 暂无同类指标价格参考 | 不展示价格参考结论，不影响商品详情查看 |
| 沟通入口为空 | 不存在 IM 入口且不允许询价/议价 | 不开放新增沟通入口 |

空状态不得：

- 展示非已上架商品作为替代。
- 自动生成议价。
- 自动修改商品状态。
- 自动补齐卖家未发布字段。

## 12. 异常状态

| 异常状态 | 触发条件 | 处理规则 |
| --- | --- | --- |
| 商品状态变化 | 买家查看期间商品从已上架变为已下架 | 禁止新增询价/议价，提示刷新状态 |
| 状态版本过期 | 买家基于旧版本发起询价或议价 | 服务端拒绝旧版本操作，要求刷新最新数据 |
| 价格有效期失效 | 当前时间超过价格有效期 | 发起议价前提示价格需重新确认 |
| 可售吨位不足 | 可售吨位不足以满足买家输入采购吨位 | 阻断或提示调整采购吨位 |
| 最小起售不满足 | 买家输入采购吨位低于最小起售数量 | 阻断提交议价诉求 |
| 权限异常 | 买家无权查看该商品或卖家企业 | 拒绝访问并记录越权日志 |
| 附件加载失败 | 检测报告或材料无法打开 | 提示稍后重试，并记录材料访问异常 |
| 数据不一致 | 指标、价格、吨位等关键字段出现前后不一致 | 以服务端最新数据为准，提示刷新 |
| 并发冲突 | 卖家在买家查看期间修改关键经营字段 | 发起操作前强制校验状态版本号 |

异常处理原则：

- 异常不得新增商品状态。
- 异常不得绕过卖家侧指标商品主状态。
- 阻断类异常必须记录异常日志。
- 涉及价格、吨位、状态、权限的操作必须以后端校验结果为准。

## 13. 与字段协议的关系

### 13.1 读取字段范围

| 字段层级 | 详情页读取字段 | 页面用途 |
| --- | --- | --- |
| 基础字段 | 指标商品 ID、卖家企业 ID、商品名称、商品品类、商品图片、商品说明、附件 | 商品识别、附件查看、详情主对象关联 |
| 指标字段 | 指标组、指标名称、指标值、指标单位、指标容差下限、指标容差上限、指标说明、核心指标标记、指标排序 | 核心指标展示、完整指标展示、议价诉求生成 |
| 经营字段 | 报价方式、报价金额、价格单位、价格有效期、历史最高成交价、历史最低成交价、库存数量、可售吨位、生产区域、交付区域、交易方式、交付方式、最小起售数量、经营备注 | 价格、吨位、交付和交易条件判断 |
| 状态字段 | 当前状态、状态版本号、最近修改时间、下架原因、下架时间 | 控制可见性、并发校验、历史追溯 |
| 沟通字段 | 是否允许询价、是否允许议价、最新沟通 ID、最新沟通时间、最新沟通内容、IM 入口标识 | 控制询价、议价和沟通入口 |

### 13.2 字段使用规则

- 详情页读取字段协议中的指标商品字段，但不直接修改字段。
- `当前状态` 决定详情页是否可打开和是否开放沟通入口。
- `状态版本号` 用于发起询价、议价、加入比较前的并发校验。
- `指标组` 是详情页核心展示对象。
- `报价金额`、`价格有效期`、`可售吨位`、`最小起售数量` 是发起议价前的关键校验字段。
- `是否允许询价`、`是否允许议价` 由卖家侧指标商品状态决定，买家侧不得覆盖。
- `最新沟通 ID`、`IM 入口标识` 只作为进入企业沟通中心的入口。

### 13.3 行为数据写入边界

详情页允许产生以下行为数据：

- 买家查看详情日志。
- 买家查看附件日志。
- 买家加入比较记录。
- 买家发起询价入口记录。
- 买家发起议价入口记录。
- 买家指标关注统计。
- 买家议价诉求草稿。

上述行为数据不得反向修改：

- 指标商品主状态。
- 指标组。
- 指标值。
- 指标容差。
- 报价金额。
- 价格有效期。
- 库存数量。
- 可售吨位。
- 最小起售数量。
- 是否允许询价。
- 是否允许议价。

- 查看核心指标。

- 查看价格、价格单位、价格有效期。
- 查看可售吨位和最小起售数量。
- 查看生产区域、交付区域、交易方式和交付方式。
- 查看附件、检测报告、规格书或资质材料摘要。
- 查看历史最高成交价、历史最低成交价等基础参考信息。
- 加入比较。
- 发起询价。
- 发起议价。

## 15. 协议结论

买家指标商品详情页是买家侧“看指标”和“聊指标”的核心承接页面。

该页面必须围绕单个已上架指标商品展开，清晰展示卖家发布的核心指标、完整指标、价格、吨位、交付条件和材料证明，并通过侧边操作区和底部操作区承接发起询价、发起议价、加入比较、进入企业沟通中心等行为。

买家在详情页只能查看、比较、沟通和提交自身议价诉求，不允许直接修改任何卖家发布的指标商品字段，也不得通过详情页改变卖家侧指标商品主状态。
