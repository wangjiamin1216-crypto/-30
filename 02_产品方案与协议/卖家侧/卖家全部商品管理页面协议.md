# 卖家全部商品管理页面协议

---

## 一、页面定位

卖家全部商品管理页面是「卖家指标经营工作台 MVP」的支撑页面，从卖家指标经营工作台的商品管理入口进入。

本页面用于集中查看、筛选和管理卖家已创建的全部指标商品，帮助卖家围绕指标商品状态、指标信息、库存/吨位、报价和审核进度完成基础经营维护。

本页面不是新的核心业务模块，不重新设计指标商品状态机，不重新定义字段协议，不扩展金融、合同、物流或完整交易链路。

页面遵循：

- 指标优先于商品名称。
- 状态驱动可操作行为。
- 字段来源于《卖家指标商品字段协议》。
- 状态来源于《卖家指标商品经营状态机协议》。
- 只服务卖家指标经营工作台 MVP 的集中管理场景。

---

## 二、页面目标

帮助卖家：

- 查看全部已创建的指标商品。
- 按状态、品类、商品名称、价格和库存快速定位指标商品。
- 判断每个指标商品当前处于草稿、待审核、审核驳回、已上架或已下架状态。
- 根据状态执行编辑、提交审核、查看审核状态、查看驳回原因、下架、重新提交等动作。
- 从集中管理页进入草稿箱或新建指标商品。

说明：

- 本页面承接工作台的商品管理入口。
- 工作台用于经营入口和概览判断，本页面用于集中管理全部指标商品。
- 本页面不替代工作台主经营区，不展开完整商品运营后台。

---

## 三、页面核心行为

卖家可以：

- 查看全部指标商品。
- 按状态筛选商品。
- 按商品品类筛选商品。
- 按商品名称搜索商品。
- 按报价金额区间搜索商品。
- 按库存数量或可售吨位区间搜索商品。
- 查看商品详情。
- 编辑商品。
- 提交审核。
- 查看审核状态。
- 查看审核进度。
- 查看驳回原因。
- 重新提交审核。
- 下架商品。
- 查看下架原因。
- 进入草稿箱。
- 新建指标商品。

行为边界：

- 所有操作必须受当前状态、卖家权限和服务端最新状态共同约束。
- 列表操作只提供入口和基础动作，不承载完整编辑表单。
- 商品详情区用于查看摘要和进入编辑，不扩展完整商品后台能力。
- 下架只改变指标商品主状态，不删除历史沟通、订单、合同或经营记录。

## 四、页面状态范围

本页面承接指标商品主状态机中的全部 5 个状态：

| 状态 | 列表展示重点 | 可操作按钮 |
| --- | --- | --- |
| 草稿 | 商品名称、商品品类、核心指标摘要、库存数量、可售吨位、报价金额、价格有效期、最近修改时间、当前状态 | 查看、编辑、提交审核、删除草稿 |
| 待审核 | 商品名称、商品品类、核心指标摘要、库存/可售吨位、报价金额、价格有效期、提交审核时间、当前状态 | 查看、查看审核进度、撤回审核 |
| 审核驳回 | 商品名称、商品品类、核心指标摘要、审核意见/驳回原因摘要、最近修改时间、当前状态 | 查看、查看驳回原因、编辑、重新提交 |
| 已上架 | 商品名称、商品品类、核心指标摘要、库存数量、可售吨位、库存预警标签、报价金额、价格有效期、待响应数量、当前状态 | 查看、修改经营信息、调整库存/吨位、进入 IM、下架 |
| 已下架 | 商品名称、商品品类、历史核心指标摘要、下架原因、下架时间、最近修改时间、当前状态 | 查看、查看下架原因、编辑、重新提交 |

说明：

- 草稿状态商品可以在本页面展示，但草稿的集中管理入口为草稿箱。
- 待审核状态不允许直接修改待审核版本；如需修改，应撤回审核或等待审核结果后处理。
- 审核驳回状态必须突出审核意见和驳回原因。
- 已上架状态是唯一允许买家查看和发起询价、议价的主状态。
- 已下架状态不得直接恢复为已上架，必须编辑并重新提交审核进入待审核。

## 五、列表字段

列表字段必须基于《卖家指标商品字段协议》，不新增独立字段体系。

| 列表展示字段 | 字段来源 | 展示说明 |
| --- | --- | --- |
| 指标商品名称 | 基础字段：商品名称 | 用于辅助识别指标商品，展示权重低于核心指标摘要 |
| 商品分类 | 基础字段：商品品类 | 用于分类筛选和卖家管理 |
| 核心指标摘要 | 指标字段：指标组、核心指标标记、指标名称、指标值、指标单位、指标容差下限、指标容差上限 | 展示 1 至 3 个核心指标摘要，突出指标经营价值 |
| 价格有效期 | 经营字段：价格有效期 | 提醒报价是否仍在有效期内 |
| 库存 | 经营字段：库存数量、可售吨位、库存预警标签 | 展示库存数量、可售吨位和必要库存提醒 |
| 报价金额 | 经营字段：报价方式、报价金额、价格单位 | 展示当前报价口径和金额 |
| 当前状态 | 状态字段：当前状态 | 展示草稿、待审核、审核驳回、已上架、已下架 |
| 更新时间 | 基础字段：最近修改时间 | 用于卖家判断最近维护情况 |
| 提交审核时间 | 状态字段：提交审核时间 | 待审核状态下优先展示 |
| 审核意见/驳回原因摘要 | 状态字段：审核意见、驳回原因 | 审核驳回状态下优先展示 |
| 下架原因/下架时间 | 状态字段：下架原因、下架时间 | 已下架状态下可展示或进入详情查看 |
| 待响应数量 | 沟通字段：待响应数量 | 已上架且存在询价、议价待响应时展示 |
| 操作按钮 | 页面操作 | 根据当前状态和权限展示允许动作 |

可弱化展示字段：

- 指标商品 ID。
- 卖家企业 ID。
- 创建人。
- 创建时间。
- 最近修改人。
- 状态版本号。
- 审核人。

说明：

- “核心指标摘要”是页面对指标字段的组合展示，不是新增字段。
- “更新时间”对应字段协议中的最近修改时间。
- 列表不展示金融、合同、物流、完整交易和复杂 BI 字段。

## 六、筛选与搜索

### 6.0 默认查询策略

默认查询规则：

| 规则项 | 规则 |
| --- | --- |
| 默认状态筛选 | 全部状态 |
| 默认排序 | 最近修改时间倒序 |
| 默认分页 | 每页 20 条 |
| 可选分页 | 20 / 50 / 100 条 |
| 默认排除 | 逻辑删除的草稿不进入默认列表 |

说明：

- 默认展示全部指标商品主状态，便于卖家统一查看经营对象。
- 从工作台状态概览进入时，可带入对应状态筛选。
- 从草稿箱入口进入时，应跳转草稿箱页面，不仅是在全部商品管理页筛选草稿。
- 所有查询结果必须以服务端最新状态为准。

### 6.1 状态筛选

支持按当前状态筛选：

- 全部。
- 草稿。
- 待审核。
- 审核驳回。
- 已上架。
- 已下架。

规则：

- 默认可展示全部状态。
- 从工作台某个状态数字进入时，可默认带入对应状态筛选。
- 从草稿箱入口进入时，应进入草稿箱页面，而不是仅在全部商品管理页筛选草稿。

### 6.2 品类筛选

支持按商品品类筛选。

字段来源：

- 基础字段：商品品类。

规则：

- 品类筛选只用于快速定位指标商品。
- 当前 MVP 不做复杂类目运营后台，不做多级类目治理能力。

### 6.3 商品名称搜索

支持按商品名称关键词搜索。

字段来源：

- 基础字段：商品名称。

规则：

- 商品名称用于辅助识别，不替代核心指标筛选。
- 搜索结果仍应突出核心指标摘要和当前状态。

### 6.4 价格区间搜索

支持按报价金额区间搜索。

字段来源：

- 经营字段：报价金额。
- 经营字段：价格单位。
- 经营字段：报价方式。

规则：

- 固定价和区间价按平台统一口径参与价格区间筛选。
- 在线询价、议价类商品如无明确报价金额，可展示为未填写或询价议价，不强行纳入价格区间命中。

### 6.5 库存区间搜索

支持按库存数量或可售吨位区间搜索。

字段来源：

- 经营字段：库存数量。
- 经营字段：可售吨位。

规则：

- 库存区间用于经营管理和补库存判断。
- 库存预警标签只作为风险标签，不新增库存状态机。

### 6.6 排序规则

当前 MVP 支持以下排序：

| 排序项 | 默认方向 | 说明 |
| --- | --- | --- |
| 最近修改时间 | 倒序 | 默认排序 |
| 创建时间 | 倒序 | 用于查看新建商品 |
| 提交审核时间 | 倒序 | 用于待审核商品 |
| 价格有效期 | 升序 | 用于发现即将失效报价 |
| 库存数量 | 升序 / 倒序 | 用于库存管理 |
| 可售吨位 | 升序 / 倒序 | 用于可售能力判断 |

说明：

- 当前 MVP 不做复杂多字段组合排序。
- 排序不改变状态机规则和按钮权限。

### 6.7 分页规则

分页规则：

- 默认每页 20 条。
- 支持切换每页 20 / 50 / 100 条。
- 翻页、筛选、搜索、排序必须共同生效。
- 筛选条件变化后，页码应回到第 1 页。
- 删除、提交审核、下架等操作后，应刷新当前页数据。
- 如当前页无数据，应回退到上一页或展示空状态。

### 6.8 查询字段范围

当前 MVP 支持以下查询字段：

- 商品名称。
- 商品品类。
- 当前状态。
- 核心指标。
- 指标名称。
- 报价金额区间。
- 库存数量区间。
- 可售吨位区间。
- 生产区域。
- 交付区域。
- 价格有效期是否失效。

说明：

- 查询字段必须来自字段协议。
- 不支持金融、合同、物流、完整订单或 BI 字段查询。

## 七、页面结构

本节输出低保真结构说明，不输出 UI、不输出代码、不输出高保真设计。

### 7.1 顶部操作区

区域目标：

- 承接工作台进入后的集中管理动作。
- 提供新建指标商品和进入草稿箱的快捷入口。

核心内容：

- 页面标题：全部指标商品。
- 商品状态数量摘要：全部、草稿、待审核、审核驳回、已上架、已下架。
- 新建指标商品按钮。
- 进入草稿箱入口。

推动行为：

- 新建指标商品。
- 进入草稿箱。
- 快速切换状态筛选。

### 7.2 筛选区

区域目标：

- 帮助卖家快速定位需要处理的指标商品。

筛选项：

- 当前状态。
- 商品品类。
- 商品名称。
- 报价金额区间。
- 库存数量区间。
- 可售吨位区间。

推动行为：

- 查询。
- 重置筛选。
- 清空筛选条件。

### 7.3 商品列表区

区域目标：

- 展示全部指标商品的核心经营信息和状态。
- 提供符合状态机的操作入口。

列表展示：

- 指标商品名称。
- 商品分类。
- 核心指标摘要。
- 库存 / 可售吨位。
- 报价金额 / 价格单位。
- 价格有效期。
- 当前状态。
- 更新时间。
- 操作按钮。

结构原则：

- 核心指标摘要优先于商品图片。
- 状态必须清晰可见。
- 操作按钮必须由状态机决定。
- 列表不展开完整商品详情，只提供查看和编辑入口。

### 7.4 批量/快捷操作区

区域目标：

- 提供当前 MVP 必要的快捷操作能力。

当前 MVP 支持：

- 批量选择用于查看选中数量。
- 清空筛选。
- 快速进入草稿箱。
- 快速新建指标商品。

当前 MVP 不支持：

- 批量上架。
- 批量下架。
- 批量改价。
- 批量改库存。
- 批量提交审核。
- 批量删除。

说明：

- 为避免绕过状态机和审核规则，复杂批量操作不进入当前 MVP。

### 7.5 空状态区

区域目标：

- 在无商品或无筛选结果时给出明确引导。

空状态类型：

- 无商品。
- 无筛选结果。
- 某状态下暂无商品。

具体规则见“八、空状态”。

### 7.6 商品详情区

区域目标：

- 让卖家在不离开管理语境的情况下查看指标商品摘要。
- 提供进入编辑、查看审核状态、查看驳回原因、查看下架原因等动作入口。

详情展示：

- 商品名称。
- 商品品类。
- 当前状态。
- 核心指标摘要。
- 指标说明摘要。
- 库存数量。
- 可售吨位。
- 库存预警标签。
- 报价方式。
- 报价金额。
- 价格单位。
- 价格有效期。
- 生产区域。
- 交付区域。
- 交易方式。
- 交付方式。
- 提交审核时间。
- 审核意见/驳回原因。
- 下架原因/下架时间。

说明：

- 商品详情区是管理页的查看摘要，不替代完整编辑页。
- 指标、经营、附件等修改应进入编辑页处理。

## 八、空状态

### 8.1 无商品

触发条件：

- 当前卖家尚未创建任何指标商品。

展示内容：

- 当前暂无指标商品。
- 引导卖家新建指标商品。
- 可提示指标商品是围绕指标、库存、报价和交付信息配置的经营对象。

允许行为：

- 新建指标商品。
- 返回卖家工作台。

### 8.2 无筛选结果

触发条件：

- 当前筛选或搜索条件下没有符合条件的指标商品。

展示内容：

- 未找到符合条件的指标商品。
- 提示卖家调整筛选条件或清空筛选。

允许行为：

- 清空筛选。
- 修改搜索条件。
- 新建指标商品。

### 8.3 某状态下暂无商品

触发条件：

- 卖家切换到某个状态后，该状态下暂无指标商品。

展示内容：

- 当前暂无该状态的指标商品。
- 根据状态给出轻量提示，例如草稿为空时引导进入草稿箱或新建，待审核为空时提示当前没有审核中商品。

允许行为：

- 切换状态。
- 清空筛选。
- 新建指标商品。

## 九、异常与权限规则

### 9.1 状态冲突

当列表展示状态与服务端最新状态不一致时：

- 操作必须以服务端最新状态为准。
- 旧状态按钮触发的动作必须被拒绝。
- 页面提示卖家刷新列表。
- 系统记录异常日志。

### 9.2 权限异常

当当前操作人无权操作某指标商品时：

- 不展示对应按钮，或执行时拒绝。
- 不允许越权查看、编辑、提交审核或下架。
- 系统记录权限异常。

### 9.3 数据异常

当商品存在资料缺失、库存异常、价格有效期失效等问题时：

- 可以展示异常提醒标签。
- 异常标签不得新增主状态。
- 阻断类异常必须说明阻断原因。
- 提交审核时必须按字段协议校验必填字段。

## 十、当前 MVP 不做

本页面当前 MVP 不做：

- 批量复杂操作。
- 批量上架。
- 批量下架。
- 批量改价。
- 批量改库存。
- 批量提交审核。
- 高级 BI。
- 交易统计分析。
- 完整商品运营后台。
- 金融功能。
- 合同完整流程。
- 物流完整流程。
- 订单履约完整流程。
- 复杂交易链路。
- 指标研究院。
- 多商品组合经营。
- 自动推荐和自动定价。

## 十一、与卖家工作台的关系

- 卖家指标经营工作台是经营入口，负责展示经营概览、待办、当前重点指标商品和快捷入口。
- 卖家全部商品管理页面是集中管理页，负责查看、筛选和管理卖家全部指标商品。
- 卖家草稿箱页面是草稿状态的集中管理页，负责管理未提交审核的指标商品草稿。

说明：

- 工作台回答“现在应该处理什么”。
- 全部商品管理页回答“我创建过哪些指标商品，它们分别处于什么状态”。
- 草稿箱回答“哪些指标商品还没提交审核，需要继续编辑或删除”。

## 十四、是否建议进入低保真绘制

建议进入低保真绘制。

原因：

- 页面目标、状态范围、列表字段、筛选条件和操作边界已经明确。
- 本页面是工作台的支撑管理页，适合用低保真验证信息密度、状态筛选、列表操作和详情抽屉的布局关系。
- 低保真阶段应重点验证状态筛选、指标摘要展示、操作按钮随状态变化、空状态引导和与草稿箱的跳转关系。

低保真绘制时不应进入高保真视觉、不应扩展完整商品后台、不应新增状态机或字段体系。
