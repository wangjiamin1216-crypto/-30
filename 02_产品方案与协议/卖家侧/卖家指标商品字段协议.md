# 指标商品字段协议

---

## 1. 字段分层

本协议定义对象为：**指标商品**。

指标商品字段当前只服务于：

- 指标经营。
- 库存经营。
- 基础询价、议价入口。
- 商品经营状况的基础统计展示。

字段分为以下 5 层：

| 字段层级 | 说明 | 当前用途 |
| :-: | --- | --- |
| 基础字段 | 描述指标商品的基础识别信息、归属信息和展示基础信息 | 用于创建、识别、审核和基础展示 |
| 指标字段 | 描述商品核心指标、指标值、指标单位、容差和指标说明 | 用于突出卖家优势指标、支持买家理解和议价 |
| 经营字段 | 描述价格、库存数量、可售吨位、产地及交付区域等经营信息 | 用于卖家经营维护和买家基础询价判断 |
| 状态字段 | 描述指标商品当前生命周期状态、审核结果和状态变更信息 | 用于状态机流转、审核和审计追踪 |
| 沟通字段 | 描述基础询价、议价入口和待响应提醒 | 用于进入 IM、查看最新询价议价消息和待处理数量 |

说明：

- 结构协议中的商品经营状况模块，属于指标商品经营字段的系统统计展示。
- 结构协议中的账户、物流、合同、成交进度、同类排行等内容，仅作为工作台辅助入口或聚合展示字段，不纳入指标商品主字段。

## 3. 字段与状态关系

### 3.1 草稿

草稿状态下，卖家可以编辑基础字段、指标字段和经营字段。

规则：

- 当前状态、创建人、创建时间、卖家企业 ID、指标商品 ID 不允许编辑。
- 询价、议价入口关闭。
- 待响应数量、最新沟通信息不应产生新的买家侧数据。
- 库存数量、可售吨位可以维护，但仅作为草稿经营信息。

### 3.2 待审核

待审核状态下，待审核版本应被冻结。

规则：

- 基础字段、指标字段、经营字段原则上禁止修改。
- 如卖家需要修改，应先撤回审核或等待审核结果后再修改。
- 审核意见在审核完成前可以为空。
- 询价、议价入口关闭。
- 库存字段作为待审核版本的一部分，不允许无记录修改。

### 3.3 审核驳回

审核驳回状态下，卖家可以根据审核意见修改后重新提交。

规则：

- 审核意见和驳回原因必须存在。
- 审核意见、驳回原因、审核人、审核时间不得被卖家编辑。
- 基础字段、指标字段、经营字段允许修改。
- 修改后重新提交会生成新的待审核版本。
- 历史审核意见不得覆盖，只能追加新记录。

### 3.4 已上架

已上架状态下，指标商品正式进入经营。

规则：

- 当前状态为已上架时，询价、议价入口开放。
- 核心指标字段原则上禁止直接修改。
- 商品名称、品类、核心指标、指标值、指标单位、指标容差等影响审核主版本的字段禁止无审核修改。
- 库存数量、可售吨位、库存预警阈值、经营备注等经营字段允许按规则修改。
- 报价、价格有效期、交付区域、交付方式等可能影响买家决策的字段，如允许修改，必须记录审计日志。
- 历史最高成交价、历史最低成交价由系统根据历史成交记录统计生成，不允许人工编辑。
- 商品售卖次数、商品售卖总量、商品售卖总额、被查看次数、买家近期关注指标、上次成交买家、成交最多买家由系统统计生成，不允许人工编辑。
- 库存预警标签由系统生成，不允许人工编辑。

### 3.4.1 已上架后字段修改分类

已上架状态下，字段修改必须区分为“可直接修改”“需重新审核”“不可人工修改”三类。

#### 可直接修改，不重新审核

以下字段属于经营维护字段，可在已上架状态下直接修改，但必须记录审计日志：

- 库存数量。
- 可售吨位。
- 库存预警阈值。
- 最小起售数量。
- 经营备注。
- 指标排序。

说明：

- 上述字段修改不改变指标商品主状态。
- 上述字段修改不得绕过库存、数值和权限校验。

#### 修改后需要重新审核

以下字段影响审核主版本或买家关键决策，已上架后不得直接覆盖线上版本；如需修改，应生成新的待审核版本：

- 商品名称。
- 商品品类。
- 商品图片。
- 商品说明。
- 附件。
- 核心指标标记。
- 指标名称。
- 指标值。
- 指标单位。
- 指标容差下限。
- 指标容差上限。
- 指标说明。
- 报价方式。
- 报价金额。
- 价格单位。
- 价格有效期。
- 生产区域。
- 交付区域。
- 交易方式。
- 交付方式。

说明：

- 新待审核版本审核通过后，才可更新线上经营版本。
- 新待审核版本审核驳回时，原已上架版本不应被覆盖。
- 重新审核过程必须记录状态日志和审核日志。

#### 不可人工修改

以下字段由系统生成或统计，不允许人工修改：

- 指标商品 ID。
- 卖家企业 ID。
- 创建人。
- 创建时间。
- 最近修改人。
- 最近修改时间。
- 当前状态。
- 状态版本号。
- 提交审核时间。
- 提交审核人。
- 审核人。
- 审核时间。
- 审核结果。
- 审核意见。
- 驳回原因。
- 下架原因。
- 下架时间。
- 库存预警标签。
- 历史最高成交价。
- 历史最低成交价。
- 商品售卖次数。
- 商品售卖总量。
- 商品售卖总额。
- 被查看次数。
- 买家近期关注指标。
- 上次成交买家。
- 成交最多买家。
- 最新沟通 ID。
- 最新沟通时间。
- 最新沟通内容。
- IM 入口标识。

### 3.5 已下架

已下架状态下，指标商品停止当前经营。

规则：

- 询价、议价入口关闭。
- 不允许买家基于该指标商品发起新的询价、议价。
- 历史沟通字段可查看但不产生新入口。
- 卖家可以编辑基础字段、指标字段和经营字段后重新提交审核。
- 下架原因、下架时间不得删除或覆盖。

## 4. 字段校验规则

### 4.1 基础字段校验

- 指标商品 ID 必须唯一。
- 卖家企业 ID 必须存在且与当前操作人权限匹配。
- 商品名称不能为空。
- 商品品类不能为空。
- 附件如作为审核必要材料，则提交审核时必须存在。
- 商品图片不是当前 MVP 的核心交易字段，但如上传，必须满足平台允许的格式和数量要求。

### 4.1.1 商品图片上传规则

商品图片用于辅助识别指标商品，不高于指标信息优先级。

MVP 上传规则：

| 规则项 | 规则 |
| --- | --- |
| 支持格式 | JPG、JPEG、PNG |
| 单张大小 | 不超过 5MB |
| 图片数量 | 1 至 5 张 |
| 是否必填 | 默认非必填；如品类或审核规则要求，可配置为必填 |
| 支持能力 | 上传、预览、删除、替换 |
| 日志要求 | 上传、删除、替换需记录操作日志 |

处理规则：

- 图片缺失默认不阻断提交审核，除非平台审核规则要求该品类必须上传图片。
- 图片格式、大小或数量不符合规则时，应阻断上传。
- 图片异常可作为平台审核驳回原因。
- 图片上传能力不扩展为完整素材管理或图片库。

### 4.1.2 附件上传规则

附件用于支持审核判断，包括检测报告、资质材料、规格书等。

MVP 上传规则：

| 规则项 | 规则 |
| --- | --- |
| 支持格式 | PDF、DOC、DOCX、XLS、XLSX、PNG、JPG、JPEG |
| 单个附件大小 | 不超过 10MB |
| 附件数量 | 最多 10 个 |
| 常见附件 | 检测报告、资质材料、规格书 |
| 是否必填 | 按品类或审核规则决定 |
| 支持能力 | 上传、预览或下载、删除、替换 |
| 日志要求 | 上传、删除、替换需记录操作日志 |

处理规则：

- 附件如作为当前品类审核必要材料，则提交审核时必须存在。
- 附件格式、大小或数量不符合规则时，应阻断上传。
- 附件缺失、不可预览或内容不符，可作为平台审核驳回原因。
- 附件能力不扩展为完整文件中心、证照中心或素材管理系统。

### 4.2 指标字段校验

- 指标组不能为空。
- 至少存在一个核心指标。
- 指标名称不能为空。
- 指标值不能为空。
- 指标单位不能为空。
- 同一指标商品下，核心指标名称不应重复。
- 指标容差下限和指标容差上限必须与指标值类型匹配。
- 指标容差下限不得大于指标容差上限。
- 如指标值为数值型，容差范围必须是合法数值范围。
- 指标说明不得与指标值、指标单位形成明显冲突。

### 4.3 经营字段校验

- 库存数量不能为空，且不得小于 0。
- 可售吨位不能为空，且不得小于 0。
- 可售吨位不得大于库存数量，除非平台明确允许按特殊经营口径配置。
- 库存预警阈值不得小于 0。
- 报价方式不能为空。
- 如报价方式为固定价或区间价，报价金额不能为空。
- 报价金额不得小于 0。
- 价格单位不能为空。
- 价格有效期如填写，不得早于当前时间。
- 价格有效期失效后，应提示卖家更新报价或重新确认经营信息。
- 历史最高成交价和历史最低成交价不得人工录入或人工修改。
- 历史最高成交价不得小于历史最低成交价。
- 历史最高成交价、历史最低成交价如无历史成交记录，可以为空。
- 商品售卖次数、商品售卖总量、商品售卖总额、被查看次数不得小于 0。
- 买家近期关注指标、上次成交买家、成交最多买家只能由系统根据经营记录统计生成。
- 最小起售数量不得小于 0。
- 最小起售数量不得大于可售吨位，除非卖家只接受批量询价且平台允许。
- 交付区域不能为空。
- 交易方式不能为空。
- 交付方式不能为空。

### 4.4 状态字段校验

- 当前状态只能是：草稿、待审核、审核驳回、已上架、已下架。
- 状态变更必须符合状态机协议。
- 待审核进入已上架时，审核结果必须为审核通过。
- 待审核进入审核驳回时，审核结果必须为审核不通过，且审核意见、驳回原因不能为空。
- 已上架进入已下架时，下架原因不能为空。
- 状态版本号每次关键字段修改或状态流转时必须更新。
- 不允许客户端直接修改当前状态字段。

### 4.5 沟通字段校验

- 只有已上架状态允许询价、议价入口为开启。
- 草稿、待审核、审核驳回、已下架状态下，是否允许询价和是否允许议价必须为关闭。
- 待响应数量不得小于 0。
- 最新沟通 ID、最新沟通时间、最新沟通内容只能由系统根据实际询价、议价或 IM 记录生成。
- 已下架后不得生成新的买家询价、议价入口。

### 4.6 审计校验

- 影响审核主版本的字段修改必须记录审计日志。
- 影响买家决策的经营字段修改必须记录审计日志。
- 状态字段变化必须记录状态日志。
- 审核意见、驳回原因、下架原因不得覆盖，只能追加或保留历史记录。
- 并发修改时，必须校验状态版本号，拒绝过期版本提交。

## 5. 当前 MVP 边界说明

当前字段仅服务于：

- 指标经营。
- 库存经营。
- 基础询价、议价沟通入口。
- 商品经营状况基础统计展示。

### 5.1 指标经营边界

字段围绕指标商品的创建、审核、上架、下架和重新提交展开，重点表达：

- 商品作为指标载体。
- 指标名称、指标值、指标单位和指标容差。
- 指标说明与核心指标标记。
- 指标修改的审计追踪。

### 5.2 库存经营边界

库存当前不是独立状态机，只作为指标商品的经营字段和风险标签，重点表达：

- 库存数量。
- 可售吨位。
- 库存预警阈值。
- 库存预警标签。

库存字段可以影响提交审核、经营提醒和已上架后的经营判断，但不扩展为库存状态机。

### 5.3 基础询价、议价沟通入口边界

沟通当前不是独立状态机，只作为基础入口和待办提醒，重点表达：

- 是否允许询价。
- 是否允许议价。
- 待响应数量。
- 最新沟通入口。
- 进入 IM 的入口标识。

当前不定义完整沟通生命周期，不定义报价单、订单、合同、履约、物流等后续交易字段。

### 5.4 工作台辅助入口边界

结构协议中的顶部概览、右侧经营待办区和底部辅助能力区可以展示订单、合同、物流、账户相关的聚合数字、摘要和入口。

边界规则：

- 这些字段只用于页面入口和提醒展示。
- 这些字段不纳入指标商品主字段。
- 这些字段不参与指标商品审核。
- 这些字段不触发指标商品状态流转。
- 这些字段不扩展为完整订单、合同、物流、账户或履约字段协议。

### 5.5 当前不扩展字段范围

当前 MVP 不纳入以下字段域：

- 金融字段。
- 合同字段。
- 履约字段。
- 物流字段。
- 风控字段。
- BI 字段。
- 结算字段。
- 发票字段。
- 复杂订单字段。
- 复杂沟通流程字段。

本协议只定义指标商品当前阶段所需的最小字段集合，避免过早扩展非 MVP 业务域。
