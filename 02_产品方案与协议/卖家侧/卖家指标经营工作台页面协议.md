# 卖家指标经营工作台页面协议

## 一、页面目标

帮助卖家：

- 快速经营指标化商品
- 快速调整指标
- 快速维护库存/吨位/价格
- 快速响应买家的询价需求
- 快速推进成交
- 快速完成待办事项

本页面服务对象是：**卖家指标商品经营**。

页面核心目标不是做完整卖家后台，而是让卖家围绕“指标商品”完成当前 MVP 的经营闭环：

新建指标商品
→ 保存草稿
→ 提交审核
→ 处理审核结果
→ 上架经营
→ 维护库存/吨位/价格
→ 响应基础询价、议价沟通

---

## 二、页面核心原则

- 指标优先于商品名称
- 指标权重优先于图片权重
- 当前库存必须突出
- 核心指标必须突出
- 企业沟通中心必须可快速进入
- 企业沟通中心必须常驻
- 当前待处理事项必须常驻
- 经营态下经营数据必须常驻
- 订单、合同、售后只作为顶部待办聚合数字展示
- 金融、合同、物流、履约不在当前 MVP 中展开完整流程

说明：

- 当卖家没有任何指标商品、订单、物流、沟通和经营数据时，页面不进入经营态，而进入新手空状态。
- 新手空状态下，经营数据总览应替换为首次经营引导，不展示大量 0 值经营数据。
- 页面所有操作必须受指标商品当前状态、角色权限和服务端最新状态共同约束。

---

## 三、页面核心模块

1. 指标商品经营数据总览
2. 待办事项概览
3. 待响应沟通消息概览
4. 指标商品经营模块
5. 商品经营状况模块
6. 指标经营建议区
7. 同类指标商品销售排行区
8. 成交进度跟踪区
9. 企业沟通中心入口
10. 商品管理入口区
11. 账户管理入口区
12. 物流管理入口区
13. 合同管理入口区

说明：

- 库存数量、可售吨位、库存预警、报价、价格有效期等经营信息归入指标商品经营模块承载。
- 订单、合同、物流、账户相关内容仅作为待办聚合或辅助入口展示，不展开完整流程。
- 成交进度跟踪区只作为经营提醒和入口展示，不定义订单、合同、物流、售后或履约状态机。
- 指标经营建议区、同类指标商品销售排行区只作为经营参考，不扩展为指标研究院、BI 分析或自动推荐系统。

## 四、页面核心行为

卖家可以：

- 新建指标商品
- 修改指标
- 修改商品图片
- 新增指标
- 上传附件
- 调整库存/吨位
- 修改价格
- 修改价格有效期
- 修改指标说明
- 查看经营建议入口
- 查看同类指标商品销售排行
- 查看成交进度跟踪
- 响应买家询价、议价消息
- 快速进入企业沟通中心
- 提交审核
- 撤回审核
- 查看驳回原因
- 重新提交审核
- 下架
- 查看全部商品
- 查看草稿箱
- 查看账户交易记录
- 查看运输进度
- 查看合同

行为约束：

- 新建指标商品不依赖已有指标商品状态。
- 保存草稿只适用于草稿状态。
- 提交审核只适用于草稿状态。
- 撤回审核只适用于待审核状态。
- 查看驳回原因只适用于审核驳回状态。
- 重新提交审核只适用于审核驳回和已下架状态。
- 下架只适用于已上架状态。
- 进入企业沟通中心处理询价、议价，只在已上架且存在沟通入口时开放。
- 账户、物流、合同相关行为只作为辅助入口，不改变指标商品主状态。

## 五、页面布局

顶部区域：

- 经营数据总览区
- 状态概览区
- 待办事项概览区
- 待响应沟通消息概览区

核心工作区：
- 指标商品经营模块
- 商品经营状况模块

辅助工作区：
- 指标经营建议区
- 同类指标商品销售排行区
- 成交进度跟踪区

底部区域：
- 商品管理入口区
- 账户管理入口区
- 物流管理入口区
- 合同管理入口区

弹窗/抽屉交互区：
- 查看全部商品
- 草稿箱
- 企业沟通中心
- 查看账户交易记录
- 前往发货
- 查看驳回原因
- 查看合同

说明：

- 顶部区域只承载聚合概览，不承载单个指标商品的编辑、审核处理、库存维护和价格维护。
- 核心工作区承载单个指标商品的指标、审核状态、库存、吨位、价格、价格有效期和经营信息维护。
- 辅助工作区只提供经营建议、同类排行和成交进度入口，不扩展完整指标研究院、BI 或订单履约。
- 底部区域只保留商品、账户、物流、合同的辅助入口，不展开完整账户资金、物流履约或合同流程。

## 六、页面状态呈现规则

本页面承接指标商品主状态，但页面本身不是状态机。

指标商品主状态只包含：

- 草稿
- 待审核
- 审核驳回
- 已上架
- 已下架

### 6.1 草稿状态

页面展示重点：

- 当前状态：草稿。
- 指标完整性。
- 库存数量。
- 可售吨位。
- 最小起售数量。
- 报价金额、价格单位、价格有效期、交易方式、交付方式。
- 必填字段缺失提醒。

页面允许行为：

- 编辑指标商品。
- 修改指标。
- 修改商品图片。
- 上传附件。
- 修改库存/吨位。
- 修改价格和价格有效期。
- 保存草稿。
- 提交审核。
- 删除草稿。

页面禁止行为：

- 不展示买家可见状态。
- 不开放询价、议价入口。
- 不进入企业沟通中心处理该商品的新沟通。

### 6.2 待审核状态

页面展示重点：

- 当前状态：待审核。
- 提交审核时间。
- 提交审核人。
- 待审核版本信息。
- 审核进度。

页面允许行为：

- 查看待审核内容。
- 查看审核进度。
- 撤回审核。

页面禁止行为：

- 不允许直接编辑待审核版本。
- 不开放询价、议价入口。
- 不对买家展示。

### 6.3 审核驳回状态

页面展示重点：

- 当前状态：审核驳回。
- 审核意见。
- 驳回原因。
- 被驳回的指标或经营信息。
- 可修改字段。

页面允许行为：

- 查看驳回原因。
- 查看审核意见。
- 编辑指标商品。
- 修改指标。
- 修改经营信息。
- 修改库存/吨位。
- 上传或替换附件。
- 保存修改。
- 重新提交审核。

页面禁止行为：

- 不允许直接上架。
- 不允许忽略审核意见直接生效。
- 不开放询价、议价入口。

### 6.4 已上架状态

页面展示重点：

- 当前状态：已上架。
- 核心指标。
- 库存数量。
- 可售吨位。
- 最小起售数量。
- 库存预警标签。
- 报价金额、价格单位、价格有效期。
- 交易方式、交付方式。
- 待响应数量。
- 最新沟通时间和最新沟通内容。

页面允许行为：

- 查看经营信息。
- 修改允许范围内的经营信息。
- 调整库存/吨位。
- 查看库存预警。
- 查看待响应数量。
- 进入企业沟通中心。
- 下架。

页面禁止行为：

- 不允许无审核修改核心指标、指标值、指标单位、指标容差等影响审核主版本的字段。
- 不允许绕过权限下架。
- 不允许删除历史沟通、订单、合同记录。

### 6.5 已下架状态

页面展示重点：

- 当前状态：已下架。
- 下架原因。
- 下架时间。
- 历史核心指标。
- 历史经营信息。

页面允许行为：

- 查看历史信息。
- 查看下架原因。
- 编辑后重新提交审核。

页面禁止行为：

- 不开放新的询价、议价入口。
- 不允许直接恢复已上架。
- 不允许删除下架原因和历史经营记录。

## 七、核心按钮出现规则

| 指标商品状态 | 主按钮 | 次按钮 | 禁止出现的按钮 |
| --- | --- | --- | --- |
| 草稿 | 提交审核 | 编辑、保存、删除 | 撤回审核、重新提交、下架、进入 IM |
| 待审核 | 查看审核进度 | 撤回审核、查看 | 编辑、保存、提交审核、重新提交、下架、进入 IM |
| 审核驳回 | 重新提交审核 | 查看驳回原因、编辑、保存 | 提交审核、撤回审核、下架、进入 IM |
| 已上架 | 调整库存/吨位、进入 IM | 修改经营信息、查看、下架 | 提交审核、撤回审核、重新提交、删除草稿 |
| 已下架 | 重新提交审核 | 查看下架原因、编辑、查看 | 下架、进入 IM、提交审核、撤回审核 |

按钮规则：

- 按钮必须以服务端最新状态为准。
- 状态变化后，旧状态按钮必须失效。
- 没有权限的按钮不得出现或不得可执行。
- 触发状态变化的按钮必须记录状态日志。
- 影响审核主版本的操作必须进入审核流程。

## 八、新手空状态页面规则

当卖家刚完成企业认证，且没有商品、订单、物流、沟通和经营数据时，页面进入新手空状态。

新手空状态页面不是经营后台，而是：

- 经营启动页。
- 新手引导页。
- 首次经营激活页。

触发条件：

- 指标商品数量 = 0。
- 草稿指标商品数量 = 0。
- 待审核指标商品数量 = 0。
- 审核驳回指标商品数量 = 0。
- 已上架指标商品数量 = 0。
- 已下架指标商品数量 = 0。
- 无待响应沟通消息。
- 无成交订单记录。
- 无合同、物流、售后待办。
- 无经营数据。

页面调整规则：

- 顶部经营数据总览替换为首次经营启动提示。
- 主经营区替换为发布第一个指标商品模块。
- 右侧待办/建议区替换为新手经营指引、高频指标排行、高频讨论问题、新手帮助。
- 商品管理入口保留发布新商品、查看全部商品、草稿箱。
- 账户、物流、合同入口可保留缺省入口，但不得展示完整流程。

新手空状态主行为：

- 发布第一个指标商品。

新手空状态结束条件：

- 已创建第一个指标商品草稿。
- 已保存第一个指标商品草稿。
- 已提交第一个指标商品审核。
- 已存在待审核、审核驳回、已上架或已下架指标商品。

说明：

- 新手空状态不是指标商品状态。
- 新手空状态不进入指标商品状态机。
- 一旦卖家产生过指标商品生命周期记录，即使当前没有已上架商品，也不应回到完整新手空状态。

## 九、模块边界说明

### 9.1 指标商品经营模块

模块承载：

- 当前状态。
- 商品名称。
- 商品品类。
- 核心指标。
- 指标值。
- 指标单位。
- 指标容差。
- 指标说明。
- 附件。
- 库存数量。
- 可售吨位。
- 报价金额。
- 价格有效期。
- 生产区域。
- 交付区域。
- 交易方式。
- 交付方式。

模块边界：

- 该模块是工作台主经营模块。
- 库存和价格在当前 MVP 中归入指标商品经营信息，不形成独立页面状态机。

### 9.2 商品经营状况模块

模块承载：

- 商品售卖次数。
- 商品售卖总量。
- 商品售卖总额。
- 被查看次数。
- 买家近期关注指标。
- 上次成交买家。
- 成交最多买家。

模块边界：

- 只作为系统统计和经营参考。
- 不触发指标商品主状态变化。
- 不扩展为 BI 分析。

### 9.3 待响应沟通消息概览与企业沟通中心入口

模块承载：

- 待响应数量。
- 最新沟通时间。
- 最新沟通内容。
- IM 入口。

模块边界：

- 只保留基础询价、议价入口和待响应提醒。
- 不定义沟通状态机。
- 不扩展报价单、订单、合同或履约流程。

### 9.4 指标经营建议区与同类指标商品销售排行区

模块承载：

- 指标匹配度。
- 近 7 天成交区间。
- 近 7 天成交均价。
- 当前报价。
- 指标价格建议。
- 经营建议。
- 同类指标商品名称。
- 商品价格。
- 库存数量。
- 最新成交价。

模块边界：

- 只作为经营参考。
- 不自动生成指标。
- 不形成个性化推荐。
- 不扩展指标研究院或 BI 分析。

### 9.5 成交进度跟踪区

模块承载：

- 订单编号。
- 客户名称。
- 成交时间。
- 询价。
- 报价。
- 订单确认。
- 合同签署。
- 商品发货。
- 售后处理。
- 交易完成。

模块边界：

- 只作为成交进度入口和摘要提醒。
- 不定义订单、合同、物流、售后或履约状态机。
- 不反向改变指标商品主状态。

### 9.6 底部辅助能力区

模块承载：

- 商品管理入口。
- 账户管理入口。
- 物流管理入口。
- 合同管理入口。

模块边界：

- 仅作为辅助入口或摘要展示。
- 不展开完整账户资金、物流履约、合同管理或完整交易流程。
- 不改变指标商品主状态。

## 十、页面与协议关系

本页面协议只定义卖家指标经营工作台的页面目标、页面模块、页面行为和页面状态呈现规则。

本页面协议不重新定义：

- 指标商品主状态。
- 指标商品状态流转。
- 字段定义、字段类型、字段必填规则。
- 字段编辑权限。
- 新手空状态的完整触发与结束规则。
- 库存、沟通、订单、合同、物流、账户等独立状态机。

说明：

- 页面协议中的状态说明，只用于指导页面如何展示和隐藏模块、按钮、提醒。
- 页面协议中的字段说明，只用于指导页面承接哪些信息，不替代字段协议。
- 页面协议中的新手空状态说明，只用于指导页面如何从经营态替换为空状态，不替代新手状态协议。
- 页面协议中的订单、合同、物流、账户内容，只作为入口、聚合数字或摘要提醒，不扩展完整流程。

| 内容 | 规则来源 |
| --- | --- |
| 页面目标、页面模块、页面行为 | 本页面协议 |
| 页面信息层级、区域划分、字段展示关系 | 卖家指标经营工作台结构协议 |
| 指标商品状态、状态流转、异常、库存预警 | 卖家指标商品经营状态机协议 |
| 字段分层、字段校验、字段与状态关系 | 卖家指标商品字段协议 |
| 新手空状态触发条件和页面替换规则 | 卖家工作台新手状态协议 |

规则优先级：

- 页面实现与状态机冲突时，以状态机协议为准。
- 页面字段展示与字段协议冲突时，以字段协议为准。
- 页面结构与结构协议冲突时，以结构协议为准。
- 新手空状态与经营态展示冲突时，先判断是否命中新手空状态。

## 当前 MVP 不做

- AI 自动生成指标
- 指标实验室
- 多商品组合
- 自动推荐
- 碳足迹
- 金融
- 合同完整流程
- 订单履约
- 物流完整流程
- 账户资金管理的完整流程
- 指标研究院
- BI 分析
- 复杂履约
- 完整新手任务中心
- 积分体系
- 成长体系

说明：

- 订单、合同、物流、账户在当前 MVP 中只允许作为入口、聚合数字或摘要提醒存在。
- 当前 MVP 不定义金融、合同、物流、履约、库存、沟通的独立状态机。
