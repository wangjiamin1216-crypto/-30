# 卖家指标经营工作台 MVP 研发评审交付

---

## 1. MVP业务目标

卖家指标经营工作台 MVP 的目标，是帮助卖家围绕“指标商品”完成最小经营闭环。

当前平台交易的核心不是传统商品展示，而是：

- 指标。
- 指标组合。
- 指标容差。
- 指标协商能力。
- 指标调整能力。

因此，卖家工作台当前不是完整后台，也不是传统商品管理中心，而是卖家进行指标商品经营的核心入口。

当前 MVP 要解决的问题：

- 卖家可以发布第一个指标商品。
- 卖家可以围绕指标、库存、吨位、价格、附件等信息完成经营维护。
- 卖家可以保存草稿、提交审核、处理驳回、重新提交。
- 平台可以审核卖家提交的指标商品。
- 审核通过后，指标商品进入已上架经营状态。
- 已上架商品可以被买家查看，并开放询价、议价和 IM 入口。
- 卖家可以在已上架后维护允许范围内的经营信息，并在需要时下架商品。
- 卖家可以在工作台查看全部商品
- 卖家可以在工作台查看草稿箱

## 2. 当前 MVP 范围

### 2.1 当前做什么

当前 MVP 聚焦以下能力：

| 模块 | 当前范围 |
| --- | --- |
| 新手空状态 | 引导新卖家发布第一个指标商品 |
| 指标商品创建 | 支持填写基础信息、指标信息、库存/吨位、价格、附件 |
| 草稿管理 | 支持保存草稿、编辑草稿、删除草稿、提交审核 |
| 指标商品审核 | 支持待审核、平台审核通过、平台审核驳回 |
| 驳回处理 | 支持查看驳回原因、修改后重新提交 |
| 上架经营 | 审核通过后进入已上架状态 |
| 已上架维护 | 支持修改允许范围内的经营字段、调整库存/吨位、进入 IM、下架 |
| 已下架处理 | 支持查看下架原因、编辑后重新提交 |
| 工作台展示 | 展示指标商品经营、商品经营状况、待办、沟通入口、辅助入口、查看全部商品入口、查看草稿箱入口 |
| 全部商品管理 | 支持查看全部指标商品、按状态/品类/名称/价格/库存筛选、查看详情、编辑、提交审核、查看审核状态、下架、进入草稿箱、新建指标商品 |
| 草稿箱 | 支持集中查看草稿、继续编辑、提交审核、删除草稿、新建指标商品 |
| 平台审核端 | 支持待审核列表、审核详情、审核通过、审核驳回、审核日志、强制下架 |

### 2.2 当前不做什么

当前 MVP 不做：

- 完整金融能力。
- 完整合同流程。
- 完整订单履约。
- 完整物流流程。
- 完整账户资金管理。
- 完整风控系统。
- 完整 BI 分析。
- 指标研究院。
- AI 自动生成指标。
- AI 智能运营。
- 个性化推荐。
- 多商品组合经营。
- 完整新手成长体系。
- 积分体系。
- 新手任务中心。

边界说明：

- 订单、合同、物流、账户只作为工作台辅助入口或聚合提醒。
- 沟通当前只保留询价、议价、IM 入口和待响应提醒，不定义沟通状态机。

## 3. 核心业务链路

### 3.1 新卖家首次经营链路

```text
新卖家完成企业认证
↓
进入卖家指标经营工作台
↓
命中新手空状态
↓
点击发布第一个指标商品
↓
进入新建指标商品页
↓
填写基础信息、指标信息、库存/吨位、价格与附件
↓
保存草稿
↓
提交审核
↓
进入待审核状态页
↓
平台审核
↓
审核通过
↓
指标商品进入已上架
↓
卖家进入经营态工作台
```

对应页面：

| 步骤 | 页面 |
| --- | --- |
| 企业认证后首次进入 | 新手空状态页 |
| 发布第一个指标商品 | 新建指标商品页 |
| 保存草稿 | 草稿箱 / 编辑页 |
| 提交审核 | 待审核状态页 |
| 平台审核 | 平台审核列表页 / 审核详情页 |
| 审核通过 | 工作台 / 商品详情页 |
| 已上架经营 | 工作台经营态 / 商品详情页 |

### 3.2 审核驳回再提交链路

```text
卖家提交审核
↓
平台审核不通过
↓
指标商品进入审核驳回
↓
卖家查看驳回原因和审核意见
↓
卖家修改指标、经营信息、库存/吨位或附件
↓
重新提交审核
↓
进入待审核
↓
平台再次审核
↓
审核通过后已上架
```

对应页面：

| 步骤 | 页面 |
| --- | --- |
| 审核驳回 | 审核驳回状态页 |
| 查看驳回原因 | 驳回原因弹窗 / 审核意见区域 |
| 修改商品 | 编辑页 |
| 重新提交 | 编辑页 / 状态操作区 |
| 再次审核 | 平台审核详情页 |

### 3.3 已上架经营链路

```text
指标商品已上架
↓
卖家查看经营信息
↓
卖家调整库存/吨位
↓
卖家修改允许范围内的经营信息
↓
买家可查看并发起询价/议价
↓
卖家进入 IM 响应
↓
必要时卖家主动下架
```

对应页面：

| 步骤 | 页面 |
| --- | --- |
| 已上架查看 | 工作台 / 商品详情页 |
| 调整库存/吨位 | 商品编辑态 / 经营信息维护区 |
| 进入 IM | 工作台沟通入口 / 企业沟通中心 |
| 下架 | 商品详情页 / 状态操作区 |

## 4. 状态机讲解

当前状态机对象是：**指标商品**。

工作台不是状态机对象。库存不是状态机。沟通不是状态机。

### 4.1 状态列表

| 状态 | 含义 | 买家是否可见 | 是否开放询价/议价 |
| --- | --- | --- | --- |
| 草稿 | 已创建但未提交审核 | 否 | 否 |
| 待审核 | 已提交平台审核，等待处理 | 否 | 否 |
| 审核驳回 | 平台审核不通过，需修改后重提 | 否 | 否 |
| 已上架 | 审核通过，正式经营 | 是 | 是 |
| 已下架 | 停止当前经营 | 否 | 否 |

### 4.2 状态流转

```text
草稿
→ 提交审核
→ 待审核
→ 审核通过
→ 已上架

待审核
→ 审核不通过
→ 审核驳回
→ 修改后重新提交
→ 待审核

已上架
→ 卖家主动下架 / 平台强制下架 / 平台规则下架 / 经营条件失效
→ 已下架

已下架
→ 编辑并重新提交审核
→ 待审核
```

### 4.3 哪些状态允许编辑

| 状态 | 是否允许编辑 | 说明 |
| --- | --- | --- |
| 草稿 | 允许 | 基础字段、指标字段、经营字段可编辑 |
| 待审核 | 不允许直接编辑 | 待审核版本冻结；如需修改应撤回审核 |
| 审核驳回 | 允许 | 根据驳回原因修改后重新提交 |
| 已上架 | 部分允许 | 仅允许按规则修改经营字段，如库存、可售吨位、部分价格或交付说明 |
| 已下架 | 允许 | 可编辑后重新提交审核 |

### 4.4 哪些状态禁止编辑

| 状态 | 禁止内容 |
| --- | --- |
| 待审核 | 禁止直接修改待审核版本 |
| 已上架 | 禁止无审核修改核心指标、指标值、指标单位、指标容差等影响审核主版本的字段 |
| 全部状态 | 禁止客户端直接修改当前状态字段 |

### 4.5 哪些状态允许重新提交

| 状态 | 是否允许重新提交 |
| --- | --- |
| 审核驳回 | 允许 |
| 已下架 | 允许 |
| 草稿 | 使用提交审核，不叫重新提交 |
| 待审核 | 不允许重复提交，应查看进度或撤回审核 |
| 已上架 | 不允许直接重新提交；影响审核主版本的修改需进入审核流程 |

### 4.6 哪些状态允许下架

| 状态 | 是否允许下架 |
| --- | --- |
| 已上架 | 允许卖家主动下架 |
| 已上架 | 允许平台管理员强制下架 |
| 草稿、待审核、审核驳回、已下架 | 不允许执行下架动作 |

## 5. 页面与状态关系

### 5.1 工作台

承接状态：

- 新手空状态。
- 草稿。
- 待审核。
- 审核驳回。
- 已上架。
- 已下架。

页面变化：

| 状态 | 工作台展示重点 |
| --- | --- |
| 新手空状态 | 发布第一个指标商品、新手经营指引、高频指标排行、高频讨论问题 |
| 草稿 | 草稿数量、草稿入口、继续编辑和提交审核 |
| 待审核 | 审核中提示、查看审核进度、撤回审核 |
| 审核驳回 | 驳回提醒、查看驳回原因、重新提交 |
| 已上架 | 指标商品经营、库存/吨位、价格、待响应沟通、进入 IM |
| 已下架 | 下架原因、历史信息、编辑后重新提交 |

### 5.2 新建页

承接状态：

- 草稿。

页面变化：

- 首次进入新建页时，页面用于创建指标商品草稿。
- 保存后生成草稿。
- 提交审核后进入待审核。
- 草稿状态允许编辑基础信息、指标信息、经营信息、图片和附件。

### 5.3 编辑页

承接状态：

- 草稿。
- 审核驳回。
- 已下架。
- 已上架的部分经营字段维护。

页面变化：

| 状态 | 编辑页规则 |
| --- | --- |
| 草稿 | 全量可编辑，允许保存和提交审核 |
| 审核驳回 | 展示驳回原因，允许修改后重新提交 |
| 已下架 | 允许编辑后重新提交审核 |
| 已上架 | 只允许修改经营字段；核心指标修改需重新走审核 |

### 5.4 商品详情页

承接状态：

- 全部指标商品主状态。

页面变化：

- 草稿、待审核、审核驳回、已下架不对买家可见。
- 已上架对买家可见，并开放询价、议价入口。
- 卖家侧详情页需要根据状态展示对应按钮。

### 5.5 审核状态页

承接状态：

- 待审核。
- 审核驳回。

页面变化：

| 状态 | 展示重点 | 可用行为 |
| --- | --- | --- |
| 待审核 | 提交审核时间、提交人、待审核版本、审核进度 | 查看、撤回审核、查看审核进度 |
| 审核驳回 | 审核意见、驳回原因、可修改字段 | 查看驳回原因、编辑、保存、重新提交 |

### 5.6 平台审核页

承接状态：

- 待审核。
- 审核驳回。
- 已上架。
- 已下架。

页面变化：

- 待审核：允许审核通过、审核驳回。
- 审核驳回：允许查看详情和日志。
- 已上架：平台管理员允许强制下架。
- 已下架：允许查看详情和日志。

### 5.7 全部商品管理页

承接状态：

- 草稿。
- 待审核。
- 审核驳回。
- 已上架。
- 已下架。

页面变化：

| 状态 | 展示重点 | 可用行为 |
| --- | --- | --- |
| 草稿 | 商品名称、商品品类、核心指标摘要、库存/可售吨位、报价、价格有效期、最近修改时间 | 查看、编辑、提交审核、删除草稿 |
| 待审核 | 提交审核时间、待审核版本摘要、审核进度 | 查看、查看审核进度、撤回审核 |
| 审核驳回 | 审核意见、驳回原因、核心指标摘要、最近修改时间 | 查看驳回原因、编辑、重新提交 |
| 已上架 | 核心指标、库存/可售吨位、库存预警、报价、价格有效期、待响应数量 | 查看、修改经营信息、调整库存/吨位、进入 IM、下架 |
| 已下架 | 下架原因、下架时间、历史核心指标和经营信息 | 查看下架原因、编辑、重新提交 |

说明：

- 全部商品管理页是工作台的支撑管理页，不是完整商品运营后台。
- 页面列表字段必须来自字段协议，状态操作必须服从状态机。
- 草稿可以在全部商品管理页展示，但草稿的集中处理入口是草稿箱。

### 5.8 草稿箱页

承接状态：

- 草稿。

页面变化：

| 状态 | 展示重点 | 可用行为 |
| --- | --- | --- |
| 草稿 | 商品名称、商品品类、已填写完整度、核心指标摘要、库存/可售吨位、报价摘要、最后编辑时间、创建时间 | 继续编辑、提交审核、删除草稿、新建指标商品 |

说明：

- 草稿箱只展示草稿状态的指标商品。
- 待审核、审核驳回、已上架、已下架商品不进入草稿箱。
- 已填写完整度是基于必填字段完成情况的页面计算结果，不新增字段体系。
- 草稿提交审核后进入待审核，并从草稿箱移出。

## 6. 字段规则整理

本节只整理研发需要重点关注的规则，不展开完整字段表。

### 6.1 必填字段

提交审核前必须重点校验：

- 商品名称不能为空。
- 商品品类不能为空。
- 指标组不能为空。
- 至少存在一个核心指标。
- 指标名称不能为空。
- 指标值不能为空。
- 指标单位不能为空。
- 库存数量不能为空，且不得小于 0。
- 可售吨位不能为空，且不得小于 0。
- 报价方式不能为空。
- 价格单位不能为空。
- 生产区域不能为空。
- 交付区域不能为空。
- 交易方式不能为空。
- 交付方式不能为空。
- 固定价或区间价场景下，报价金额不能为空。

### 6.2 审核后不可编辑字段

待审核状态：

- 待审核版本冻结。
- 基础字段、指标字段、经营字段原则上禁止直接修改。
- 如卖家需要修改，应先撤回审核或等待审核结果。

已上架状态：

- 核心指标字段原则上禁止直接修改。
- 商品名称、品类、核心指标、指标值、指标单位、指标容差等影响审核主版本的字段，禁止无审核修改。
- 历史最高成交价、历史最低成交价由系统统计，不允许人工编辑。
- 商品售卖次数、售卖总量、售卖总额、被查看次数等经营状况字段由系统统计，不允许人工编辑。

### 6.3 上传规则

- 附件可包括规格书、检测报告、资质材料等。
- 附件如作为审核必要材料，提交审核时必须存在。
- 附件缺失可阻断提交审核或成为平台驳回原因。
- 附件预览只服务审核判断，不扩展为完整素材管理或文件中心。

### 6.4 图片规则

- 商品图片用于辅助识别，不高于指标信息优先级。
- 商品图片不是当前 MVP 的核心交易字段。
- 如上传图片，必须满足平台允许的格式和数量要求。
- 图片异常不应改变指标商品主状态，但可作为审核异常或驳回原因。

### 6.5 附件规则

- 附件在草稿、审核驳回、已下架状态允许编辑。
- 待审核状态附件属于待审核版本，不允许无记录修改。
- 审核驳回后允许上传、替换附件并重新提交。
- 历史附件变更应纳入审计或修改记录。

### 6.6 库存规则

- 库存数量不得小于 0。
- 可售吨位不得小于 0。
- 可售吨位不得大于库存数量，除非平台允许特殊经营口径。
- 库存预警阈值不得小于 0。
- 库存预警标签由系统生成，不允许人工编辑。
- 库存偏低、库存不足只作为经营提醒和风险标签，不新增库存状态机。
- 已上架状态下，如可售吨位为 0 且平台规则要求不得继续经营，可触发自动或人工下架。

### 6.7 单位规则

- 指标单位不能为空。
- 价格单位不能为空。
- 指标容差下限、容差上限必须与指标值类型匹配。
- 指标容差下限不得大于指标容差上限。
- 报价金额不得小于 0。
- 最小起售数量不得小于 0。
- 最小起售数量不得大于可售吨位，除非平台允许特殊经营口径。

## 7. 页面行为规则

### 7.1 保存草稿

适用状态：

- 草稿。

行为结果：

- 保存当前填写内容。
- 指标商品保持草稿状态。
- 不对买家可见。
- 不开放询价、议价。

研发关注：

- 保存草稿不要求全部提交审核字段完整。
- 但关键字段如指标商品 ID、卖家企业 ID、创建人、创建时间应由系统生成或记录。

### 7.2 提交审核

适用状态：

- 草稿。

行为结果：

- 草稿 → 待审核。
- 生成提交审核状态日志。
- 锁定待审核版本。
- 买家不可见。
- 不开放询价、议价。

研发关注：

- 提交前必须执行字段完整性校验。
- 提交时必须校验权限和状态版本号。
- 提交后旧页面上的草稿编辑动作应失效。

### 7.3 重新提交

适用状态：

- 审核驳回。
- 已下架。

行为结果：

- 审核驳回 → 待审核。
- 已下架 → 待审核。
- 生成新的待审核版本。
- 保留历史驳回记录、下架记录和状态日志。

研发关注：

- 审核意见、驳回原因不得覆盖。
- 下架原因、下架时间不得删除或覆盖。

### 7.4 撤回审核

适用状态：

- 待审核。

行为结果：

- 从待审核返回可编辑处理态。
- 当前 MVP 需研发评审确认撤回后的目标状态，建议回到草稿或提交前编辑态。

研发关注：

- 撤回必须校验当前状态仍为待审核。
- 如果平台已完成审核，撤回动作应失败。
- 撤回动作必须记录日志。

### 7.5 下架

适用状态：

- 已上架。

行为结果：

- 已上架 → 已下架。
- 关闭新的询价、议价入口。
- 历史沟通、历史交易记录保留。
- 生成下架状态日志。

研发关注：

- 下架必须记录下架原因。
- 下架后不得直接恢复已上架，必须编辑后重新提交审核。

### 7.6 删除草稿

适用状态：

- 草稿。

行为结果：

- 删除尚未提交审核的草稿。
- 不影响历史已审核、已上架、已下架商品。

研发关注：

- 删除草稿需要权限校验。
- 如草稿已被提交审核，删除动作必须失败。
- 删除是否物理删除或逻辑删除需研发评审确认。

## 8. 平台审核闭环

平台审核端是卖家指标经营工作台 MVP 的必要闭环。

### 8.1 平台审核端职责

平台审核端负责：

- 查看待审核指标商品。
- 核对基础信息、指标信息、库存/吨位、经营信息、图片和附件。
- 对待审核指标商品执行审核通过或审核驳回。
- 记录审核日志。
- 在必要时由平台管理员强制下架已上架商品。

### 8.2 审核通过

触发条件：

- 当前状态为待审核。
- 待审核版本存在且未撤回。
- 基础信息完整。
- 至少存在一个核心指标。
- 指标名称、指标值、指标单位完整。
- 库存、可售吨位、报价、价格单位、交付区域、交易方式、交付方式等必要经营字段完整。
- 必要图片、附件或资质材料满足审核要求。

状态结果：

- 待审核 → 已上架。
- 买家可查看。
- 开放询价、议价入口。
- 生成审核通过状态日志。

### 8.3 审核驳回

触发条件：

- 当前状态为待审核。
- 平台发现指标、商品、经营、附件、资质或合规信息不满足要求。

状态结果：

- 待审核 → 审核驳回。
- 买家不可见。
- 不开放询价、议价入口。
- 卖家可查看驳回原因并修改后重新提交。

必填要求：

- 驳回原因必填。
- 审核意见必填。
- 审核日志必须追加，不允许覆盖。

### 8.4 驳回原因

驳回原因应支持结构化记录，至少能表达：

- 基础信息缺失。
- 核心指标缺失。
- 指标值或单位异常。
- 指标容差不合理。
- 库存/可售吨位异常。
- 报价或价格有效期异常。
- 图片或附件缺失。
- 资质材料不满足要求。
- 经营信息与实际经营能力冲突。

### 8.5 强制下架

触发角色：

- 仅平台管理员。

适用状态：

- 已上架。

状态结果：

- 已上架 → 已下架。

必填要求：

- 强制下架原因必填。
- 必须记录平台操作人或系统规则来源。
- 必须记录状态日志。

## 9. 新手空状态说明

新卖家刚完成企业认证进入平台时，如果没有商品、订单、物流、沟通和经营数据，页面不应展示经营态工作台。

原因：

- 当前没有指标商品，不存在商品经营状况。
- 当前没有已上架商品，不存在询价、议价和 IM 响应。
- 当前没有订单、合同、物流、售后，不应展示完整交易链路。
- 当前没有经营数据，不应展示大量 0 值经营数据卡片。

新手空状态的页面目标：

- 引导卖家完成第一次经营行为。
- 让卖家发布第一个指标商品。
- 帮助卖家理解首次发布需要准备的基础信息、核心指标、库存/吨位、报价、附件。

空状态结束条件：

- 已创建第一个指标商品草稿。
- 已保存第一个指标商品草稿。
- 已提交第一个指标商品审核。
- 已存在待审核、审核驳回、已上架或已下架指标商品。

说明：

- 新手空状态不是指标商品状态。
- 新手空状态不进入状态机。
- 一旦卖家产生过指标商品生命周期记录，即使当前没有已上架商品，也不应回到完整新手空状态。

## 10. 当前研发重点

当前 MVP 开发阶段，研发最需要关注以下内容：

### 10.1 状态一致性

- 所有页面按钮必须由服务端最新状态控制。
- 前端缓存状态不得作为最终操作依据。
- 状态变更必须校验原状态、目标状态和状态版本号。
- 非法流转必须拒绝并记录异常。

### 10.2 页面行为联动

- 状态变化后页面按钮需要同步变化。
- 草稿、待审核、审核驳回、已上架、已下架页面展示必须不同。
- 待审核状态必须展示只读版本。
- 审核驳回状态必须突出驳回原因。
- 已上架状态才开放询价、议价和 IM 入口。

### 10.3 字段校验

- 提交审核前必须校验必填字段。
- 指标组、核心指标、指标值、指标单位、容差必须重点校验。
- 库存数量、可售吨位、报价金额、最小起售数量等数值字段必须防负数。
- 价格有效期失效需要提示或阻断。

### 10.4 审核闭环

- 卖家提交审核后，平台审核端必须能看到待审核记录。
- 平台审核通过后，卖家侧状态必须变为已上架。
- 平台审核驳回后，卖家侧必须能看到驳回原因和审核意见。
- 驳回后重新提交必须生成新待审核版本。

### 10.5 页面切换

- 新手空状态 → 新建页。
- 新建页 → 草稿箱 / 全部商品管理页 / 待审核状态页。
- 工作台 → 全部商品管理页。
- 工作台 → 草稿箱页。
- 全部商品管理页 → 草稿箱页。
- 全部商品管理页 → 商品详情页 / 编辑页 / 审核状态页。
- 草稿箱页 → 编辑页 / 待审核状态页。
- 审核驳回页 → 编辑页 → 待审核状态页。
- 已上架商品 → 经营态工作台。
- 已下架商品 → 编辑后重新提交。

### 10.6 日志与审计

- 状态变化必须记录状态日志。
- 审核意见、驳回原因、下架原因不得覆盖。
- 平台强制下架必须记录操作人和原因。
- 并发修改必须通过状态版本号处理。

## 11. 当前研发风险点

| 风险点 | 说明 | 建议 |
| --- | --- | --- |
| 状态与页面不一致 | 前端显示可操作，但服务端状态已变化 | 所有操作以服务端最新状态为准 |
| 字段遗漏 | 提交审核缺少必要指标、库存、报价或附件 | 建立提交审核前校验清单 |
| 驳回链路断裂 | 卖家无法查看驳回原因或无法重新提交 | 驳回原因、审核意见、重新提交入口必须联动 |
| 页面跳转缺失 | 新手、新建、草稿、审核、驳回之间无法闭环 | 明确每个按钮的目标页面 |
| 全部商品管理页误扩展成完整后台 | 超出 MVP 范围，带来复杂批量操作和运营系统建设 | 仅保留查看、筛选、详情、编辑入口和状态允许动作 |
| 草稿箱混入非草稿状态商品 | 状态边界不清，导致审核驳回、待审核处理混乱 | 草稿箱只查询和展示当前状态为草稿的指标商品 |
| 支撑页面绕过状态机执行操作 | 造成非法提交、下架或删除 | 全部商品管理页和草稿箱操作均以服务端最新状态为准 |
| 空状态未处理 | 新卖家进入后看到空经营数据，无法启动 | 首次进入必须命中新手空状态 |
| 待审核版本被修改 | 审核期间卖家或系统修改待审核内容 | 待审核版本必须冻结 |
| 已上架核心指标被直接修改 | 影响买家决策且绕过审核 | 核心指标变更必须重新审核 |
| 库存预警误做成状态机 | 扩大复杂度 | 库存仅作为字段和风险标签 |
| 沟通入口误做成状态机 | 扩大复杂度 | 沟通仅保留入口、待响应数量和最新消息 |
| 平台审核权限不清 | 非审核角色误操作 | 审核、强制下架必须按角色控制 |
| 审核日志覆盖 | 无法追溯历史审核意见 | 审核日志只能追加 |
| 附件/图片方案不明确 | 影响审核闭环 | 评审确认上传、预览、存储方案 |
