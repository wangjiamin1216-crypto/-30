# 卖家指标经营工作台结构协议

---

## 1. 页面信息层级

本协议将《卖家指标经营工作台页面协议》《卖家指标商品经营状态机协议》《卖家指标商品字段协议》转化为卖家指标经营工作台 MVP 的页面信息结构。

当前页面结构只服务于：

- 指标商品经营。
- 库存/吨位维护。
- 基础询价、议价入口。
- 指标商品状态处理。

本协议不输出 UI，不输出代码，不输出高保真设计，不扩展金融、合同管理、订单履约、指标研究院。

### 1.1 P0 信息

P0 信息是卖家进入工作台后必须立即判断、立即处理的信息。

| 信息 | 来源 | 目的 |
| --- | --- | --- |
| 指标商品状态分布 | 状态字段聚合 | 判断当前指标商品整体经营态势 |
| 单个指标商品当前状态 | 状态字段 | 在主经营区判断当前商品是否可经营、可审核、可修改、可下架 |
| 核心指标 | 指标字段 | 突出指标商品的核心经营价值 |
| 指标值与指标单位 | 指标字段 | 支撑卖家判断指标是否准确、是否需要修改 |
| 指标容差 | 指标字段 | 支撑买家询价、议价前的指标理解 |
| 库存数量 | 经营字段 | 判断当前库存是否足够经营 |
| 可售吨位 | 经营字段 | 判断当前可对外承诺销售能力 |
| 库存预警标签 | 经营字段 | 提醒卖家库存偏低、库存不足或库存异常 |
| 报价方式 | 经营字段 | 判断当前是否固定价、区间价或在线询价议价 |
| 报价金额 | 经营字段 | 支撑当前经营报价判断 |
| 价格有效期 | 经营字段 | 提醒卖家报价是否仍然有效 |
| 待响应数量 | 沟通字段 | 提醒卖家处理买家询价、议价 |
| 最新沟通内容 | 沟通字段 | 帮助卖家快速理解最新询价、议价内容并快速进入企业沟通中心 |
| 审核意见/驳回原因 | 状态字段 | 审核驳回状态下指导卖家修改并重新提交 |

说明：

- P0 信息代表业务优先级，不等于全部放在顶部展示。
- 库存数量、可售吨位、单个指标商品审核状态、价格、价格有效期等可操作信息，应放在主经营区承载。
- 顶部经营概览区只放聚合总览、状态概览、待办概览和待响应沟通消息概览。

### 1.2 P1 信息

P1 信息用于帮助卖家完成经营判断和次级操作，不抢占 P0 信息优先级。

| 信息 | 来源 | 目的 |
| --- | --- | --- |
| 商品名称 | 基础字段 | 辅助识别指标商品 |
| 商品品类 | 基础字段 | 支持分类查看和筛选 |
| 生产区域 | 经营字段 | 支持买家基础判断和卖家经营管理 |
| 交付区域 | 经营字段 | 支持询价前判断交付可行性 |
| 交易方式 | 经营字段 | 支持基础交易意向判断 |
| 交付方式 | 经营字段 | 支持基础经营信息判断 |
| 最小起售数量 | 经营字段 | 支持询价、议价门槛判断 |
| 历史最高成交价 | 经营字段 | 支持卖家理解历史价格上沿 |
| 历史最低成交价 | 经营字段 | 支持卖家理解历史价格下沿 |
| 指标说明 | 指标字段 | 补充指标口径、检测口径或适用条件 |

### 1.3 P2 信息

P2 信息用于完整查看、编辑、追溯或辅助判断，默认不作为页面首要信息。

| 信息 | 来源 | 目的 |
| --- | --- | --- |
| 商品图片 | 基础字段 | 辅助识别，不高于指标优先级 |
| 商品说明 | 基础字段 | 补充商品背景 |
| 附件 | 基础字段 | 支持审核、资质、检测材料查看 |
| 经营备注 | 经营字段 | 补充经营说明 |
| 指标排序 | 指标字段 | 支持卖家管理指标展示优先级 |
| 库存预警阈值 | 经营字段 | 支持库存预警配置 |
| 提交审核时间 | 状态字段 | 支持状态追溯 |
| 审核时间 | 状态字段 | 支持审核进度判断 |
| 下架原因 | 状态字段 | 支持已下架商品追溯 |
| 下架时间 | 状态字段 | 支持已下架商品追溯 |

### 1.4 应弱化展示的信息

以下信息应弱化展示，仅在详情、日志、编辑或追溯场景中出现：

- 指标商品 ID。
- 卖家企业 ID。
- 创建人。
- 创建时间。
- 最近修改人。
- 最近修改时间。
- 状态版本号。
- 审核人。
- 最新沟通 ID。
- 是否允许询价。
- 是否允许议价。

说明：

- 是否允许询价、是否允许议价由状态决定，不应作为卖家主要阅读信息。
- 指标商品 ID、状态版本号、审核人等字段主要用于系统识别、审计和追溯，不应干扰经营判断。

## 2. 页面区域划分

页面结构建议分为：

- 顶部经营概览区。
- 主经营区。
- 右侧待办/建议区。
- 底部辅助能力区。

### 2.1 顶部经营概览区

区域目标：

- 让卖家快速判断整体经营态势、待办压力和沟通压力。
- 承担总览职责，不承载单个指标商品的编辑、审核处理、库存维护和价格维护。

放置模块：

- 指标商品经营数据总览。
- 状态概览。
- 待办事项概览。
- 待响应沟通消息概览。

展示字段：

经营数据总览展示：

- 在售商品数。
- 成交金额。
- 成交订单数。
- 成交买家数。
- 商品总浏览次数。
- 商品总评价数。

状态概览展示：

- 草稿指标商品数量。
- 待审核指标商品数量。
- 审核驳回指标商品数量。
- 已上架指标商品数量。
- 已下架指标商品数量。

待办事项模块展示：

- 咨询的待响应询价消息数量。
- 待确认订单数量。
- 待签署合同数量。
- 库存不足提醒数量。
- 退款售后单数量。

待响应沟通消息概览展示：

- 最新沟通消息内容。
- 最新沟通时间。

说明：

- 待确认订单数量、待签署合同数量、退款售后单数量仅作为顶部待办聚合数字展示。
- 当前结构协议不展开订单、合同、售后对应的完整流程、字段协议或状态机。

推动行为：

- 新建指标商品。
- 处理待办事项。
- 查看待响应沟通消息。
- 进入企业沟通中心。

### 2.2 主经营区

区域目标：

- 承载单个指标商品经营的核心信息和核心操作。
- 让企业在主经营区完成商品指标的查看、编辑、修改、审核提交、库存/吨位维护和价格维护。
- 围绕指标、审核状态、库存、吨位、价格和经营信息组织页面主内容。

放置模块：

- 指标商品经营模块。
- 商品经营状况模块。


展示字段：

指标商品经营模块展示：

- 当前状态。
- 商品名称。
- 商品品类。
- 核心指标标记。
- 指标名称。
- 指标值。
- 指标单位。
- 指标容差下限。
- 指标容差上限。
- 指标说明。
- 附件。
- 库存数量。
- 可售吨位。
- 库存预警阈值。
- 库存预警标签。
- 报价方式。
- 报价金额。
- 价格单位。
- 价格有效期。
- 历史最高成交价。
- 历史最低成交价。
- 生产区域。
- 交付区域。
- 交易方式。
- 交付方式。
- 最小起售数量。
  
商品经营状况模块展示：

- 商品售卖次数。
- 商品售卖总量。
- 商品售卖总额。
- 被查看次数。
- 买家近期关注指标。
- 上次成交买家。
- 成交最多买家。

推动行为：

- 新建指标商品。
- 修改/新建指标。
- 修改指标说明。
- 修改库存/吨位。
- 修改价格。
- 修改价格有效期。
- 修改经营信息。
- 提交审核。
- 撤回审核。
- 查看驳回原因。
- 重新提交审核。
- 下架。

### 2.3 右侧经营待办区

区域目标：

- 聚合当前急需处理的指标商品经营待办。
- 提供指标经营建议入口，但不扩展成完整指标研究院、BI 或成交分析。

放置模块：

- 指标经营建议区。
- 同类指标商品销售排行区。
- 成交进度跟踪区。

展示字段：

指标经营建议区展示：

- 指标匹配度。
- 近7天成交区间。
- 近7天成交均价。
- 当前报价。
- 指标价格建议。
- 经营建议。
  
同类指标商品销售排行区展示：

- 同类指标商品名称。
- 商品价格。
- 库存数量。
- 最新成交价。
  
成交进度跟踪区展示：

- 订单编号。
- 客户名称。
- 成交时间。
- 询价。
- 报价。
- 订单确认。
- 合同签署。
- 商品发货。
- 售后处理。
- 交易完成。

推动行为：

- 修改指标。
- 查看成交进度。
- 跟进成交相关待办入口。

### 2.4 底部辅助能力区

区域目标：

- 承载低优先级辅助能力。
- 保留后续扩展空间，但 MVP 不展开完整交易、金融、订单履约、合同、物流、账户或指标研究院。

放置模块：

- 商品管理入口区
- 账户管理入口区
- 物流管理入口区
- 合同管理入口区

展示字段：

商品管理入口区展示

- 查看全部商品。
- 草稿箱。
- 发布新商品。

账户管理入口区展示

- 可用余额。
- 交易记录。
- 充值。
- 提现。
- 可用余额预警。
- 收支记录。

物流管理入口区展示：

- 收货地址。
- 发货地址。
- 商品名称。
- 商品数量。
- 买家名称。

合同管理入口区展示：

- 查看合同。
- 上传合同
- 合同管理

推动行为：

- 查看全部指标商品。
- 查看草稿。
- 新建指标商品。
- 查看交易记录。
- 账户余额的充值/提现。
- 查看运输进度。
- 前往发货。
- 上传/更新合同。

## 3. 核心模块结构

### 3.1 指标商品经营模块

模块目标：

- 展示指标商品的核心指标结构。
- 支持卖家围绕指标进行经营维护。

核心信息：

- 商品名称。
- 商品品类。
- 当前状态。
- 核心指标标记。
- 指标名称。
- 指标值。
- 指标单位。
- 指标容差下限。
- 指标容差上限。
- 指标说明。
- 附件。

推动行为：

- 新建指标商品。
- 修改指标。
- 修改指标说明。
- 修改/上传附件。
- 提交审核。
- 查看驳回原因。
- 重新提交审核。

结构原则：

- 核心指标优先于普通指标。
- 指标值、指标单位、容差必须形成可读的指标结构。
- 商品图片和商品说明只作为辅助信息。

### 3.2 库存/吨位维护模块

模块目标：

- 帮助卖家快速判断库存是否足够。
- 支持卖家维护库存数量和可售吨位。

核心信息：

- 库存数量。
- 可售吨位。
- 最小起售数量。
- 库存预警阈值。
- 库存预警标签。

推动行为：

- 修改库存/吨位。
- 修改最小起售数量。
- 调整库存预警阈值。
- 根据库存预警补充库存或下架。

结构原则：

- 库存不形成独立状态机。
- 库存预警标签只作为经营提醒和风险标签。
- 已上架状态下，库存/吨位维护应优先于非核心辅助信息。

### 3.3 待响应沟通消息模块

模块目标：

- 提醒卖家处理买家的基础询价、议价。
- 提供进入 IM 的路径。

核心信息：

- 最新沟通时间。
- 最新沟通内容。
- IM 入口。

推动行为：

- 进入 IM。
- 查看最新询价、议价。
- 响应买家沟通。

结构原则：

- 只展示沟通入口和待办提醒。
- 不定义沟通状态机。
- 不扩展报价单、订单、合同或履约流程。

### 3.4 企业沟通入口模块

模块目标：

- 保证卖家可快速进入企业沟通中心。
- 支持基础询价、议价响应。

核心信息：

- 最新沟通时间。
- 最新沟通内容。
- IM 入口标识。

推动行为：

- 进入 IM。
- 响应询价。
- 响应议价。

结构原则：

- 企业沟通入口应常驻。
- 仅保留入口、数量和最新消息提醒。
- 不定义完整 IM 产品结构。
- 不扩展沟通状态机。

## 4. 行为优先级

### 4.1 P0 行为

P0 行为必须优先展示，直接服务指标商品经营闭环。

| 行为 | 出现场景 | 目的 |
| --- | --- | --- |
| 新建指标商品 | 无可经营商品或需要新增经营商品 | 建立新的指标商品 |
| 修改指标 | 草稿、审核驳回、已下架 | 修正或完善指标结构 |
| 修改库存/吨位 | 草稿、审核驳回、已上架、已下架 | 维护当前经营能力 |
| 提交审核 | 草稿 | 推动指标商品进入审核 |
| 查看驳回原因 | 审核驳回 | 明确修改方向 |
| 重新提交审核 | 审核驳回、已下架 | 推动重新进入审核 |
| 进入 IM | 已上架且存在询价、议价入口 | 响应买家沟通 |

### 4.2 P1 行为

P1 行为用于辅助经营处理，不高于 P0 行为。

| 行为 | 出现场景 | 目的 |
| --- | --- | --- |
| 修改经营信息 | 草稿、审核驳回、已上架、已下架 | 调整报价、交付、交易等经营信息 |
| 撤回审核 | 待审核 | 允许卖家修改待审核内容 |
| 查看审核进度 | 待审核 | 降低等待不确定性 |
| 下架 | 已上架 | 停止当前指标商品经营 |
| 查看库存预警 | 草稿、审核驳回、已上架、已下架 | 判断是否需要补库存或调整可售吨位 |
| 查看最新询价、议价 | 已上架 | 快速处理买家沟通 |

### 4.3 P2 行为

P2 行为用于查看和追溯。

| 行为 | 出现场景 | 目的 |
| --- | --- | --- |
| 查看附件 | 全部状态 | 查看规格、检测、资质材料 |
| 查看历史记录 | 全部状态 | 追溯状态和字段变化 |
| 查看下架原因 | 已下架 | 理解停止经营原因 |
| 查看创建/修改信息 | 全部状态 | 支持内部追溯 |

## 5. 状态与页面展示关系

### 5.1 草稿状态

展示重点：

- 当前状态：草稿。
- 指标完整性。
- 库存数量。
- 可售吨位。
- 最小起售数量。
- 报价金额、价格单位、价格有效期、交易方式、交付方式。
- 必填字段缺失提醒。

优先行为：

- 修改指标。
- 修改库存/吨位。
- 保存草稿。
- 提交审核。

展示规则：

- 不展示买家可见或可交易状态。
- 不开放询价、议价入口。
- 沟通字段弱化展示或不展示新沟通信息。

### 5.2 待审核状态

展示重点：

- 当前状态：待审核。
- 提交审核时间。
- 提交审核人。
- 待审核版本信息。
- 审核进度。

优先行为：

- 查看。
- 撤回审核。
- 查看审核进度。

展示规则：

- 基础字段、指标字段、经营字段以查看为主。
- 不允许直接修改待审核版本。
- 不开放询价、议价入口。

### 5.3 审核驳回状态

展示重点：

- 当前状态：审核驳回。
- 审核意见。
- 驳回原因。
- 被驳回的指标或经营信息。
- 可修改字段。

优先行为：

- 查看驳回原因。
- 修改指标。
- 修改经营信息。
- 修改库存/吨位。
- 重新提交审核。

展示规则：

- 审核意见和驳回原因必须突出。
- 原审核记录不得覆盖。
- 不开放询价、议价入口。

### 5.4 已上架状态

展示重点：

- 当前状态：已上架。
- 核心指标。
- 库存数量。
- 可售吨位。
- 最小起售数量。
- 库存预警标签。
- 交易方式、交付方式、报价金额、价格单位、价格有效期。
- 历史最高成交价、历史最低成交价。
- 待响应数量。
- 最新沟通时间和最新沟通内容。

优先行为：

- 修改库存/吨位。
- 修改允许范围内的经营信息。
- 进入企业沟通中心。
- 下架。

展示规则：

- 询价、议价入口开放。
- 核心指标字段原则上不可直接修改。
- 库存预警、价格有效期、待响应数量应形成经营提醒。
- 如修改影响审核主版本，应引导重新进入审核流程。

### 5.5 已下架状态

展示重点：

- 当前状态：已下架。
- 下架原因。
- 下架时间。
- 历史核心指标。
- 历史经营信息。

优先行为：

- 查看下架原因。
- 编辑。
- 重新提交审核。

展示规则：

- 不开放新的询价、议价入口。
- 历史沟通和历史经营信息可以查看。
- 下架原因和下架时间不得删除或覆盖。

## 7. 当前 MVP 边界

本结构协议只服务于卖家指标经营工作台 MVP。

当前结构聚焦：

- 指标商品经营。
- 指标维护。
- 库存/吨位维护。
- 价格与价格有效期维护。
- 基础询价、议价入口。
- 待响应沟通提醒。
- 指标商品状态处理。

当前不扩展：

- 完整交易流程。
- 金融能力。
- 完整合同能力。
- 完整履约能力。
- 完整物流能力。
- 研究院能力。
- BI 分析能力。
- 自动推荐能力。
- AI 自动生成指标。
- 复杂沟通状态机。

边界原则：

- 卖家指标经营工作台是页面容器，不是状态机对象。
- 指标商品是当前真正具备生命周期的对象。
- 库存只作为经营字段和预警标签，不成为独立状态机。
- 沟通只保留询价、议价入口和待响应提醒，不成为独立状态机。
- 页面结构必须围绕指标、库存、状态和基础沟通入口组织。
