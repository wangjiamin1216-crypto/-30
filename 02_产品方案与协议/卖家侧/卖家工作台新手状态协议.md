# 卖家指标经营工作台新手空状态协议

---

## 1. 新手空状态页面目标

新手空状态页面用于卖家刚完成企业认证、尚未开始经营时的工作台初始呈现。

当前页面不是经营后台，而是：

- 经营启动页。
- 新手引导页。
- 首次经营激活页。

页面核心目标：

- 引导卖家完成第一次指标商品发布。
- 帮助卖家理解指标商品的基础经营规则。
- 提醒卖家准备首次发布所需的基础资料、指标信息、库存/吨位和报价信息。
- 将卖家从“已认证但未经营”推进到“已创建指标商品”或“已提交审核”。

说明：

- 新手空状态不是指标商品状态。
- 新手空状态不进入指标商品状态机。
- 新手空状态只影响卖家指标经营工作台的页面呈现。
- 页面仍然围绕指标商品经营展开，不转为通用新手中心或完整后台首页。

---

## 2. 空状态触发条件

当卖家刚完成企业认证，且尚未产生有效经营数据时，进入新手空状态。

### 2.1 必要触发条件

同时满足以下条件时，工作台进入新手空状态：

- 指标商品数量 = 0。
- 草稿指标商品数量 = 0。
- 待审核指标商品数量 = 0。
- 已上架指标商品数量 = 0。
- 已下架指标商品数量 = 0。
- 审核驳回指标商品数量 = 0。

### 2.2 辅助判断条件

以下条件用于判断页面是否应继续保持空状态：

- 无买家询价、议价沟通记录。
- 无待响应沟通消息。
- 无成交订单记录。
- 无合同待办记录。
- 无物流待办记录。
- 无库存预警记录。
- 无商品浏览、评价、成交金额等经营数据。

### 2.3 不进入空状态的情况

出现以下任一情况时，不应再展示完整新手空状态：

- 已存在草稿指标商品。
- 已存在待审核指标商品。
- 已存在审核驳回指标商品。
- 已存在已上架指标商品。
- 已存在已下架指标商品。

说明：

- 如果卖家已有草稿但没有上架商品，应进入草稿经营引导或草稿箱处理，不再视为完全新手空状态。
- 如果卖家已有待审核商品，应进入审核中经营等待状态，不再视为完全新手空状态。

## 3. 页面核心引导行为

新手空状态的行为优先级围绕“完成第一次经营行为”排序。

### 3.1 P0 行为

P0 行为必须优先展示，是页面最核心的引导动作。

| 行为 | 目标 | 说明 |
| --- | --- | --- |
| 发布第一个指标商品 | 启动首次经营 | 引导卖家创建指标商品，进入草稿创建流程 |

### 3.2 P1 行为

P1 行为用于降低首次发布门槛，辅助卖家完成 P0 行为。

| 行为 | 目标 | 说明 |
| --- | --- | --- |
| 学习发布规范 | 帮助理解发布要求 | 说明指标商品创建、审核、上架的基础规则 |
| 查看高频指标排行 | 帮助理解指标填写方式 | 提供常见指标项、单位、容差的参考，不形成自动推荐 |
| 查看高频讨论问题 | 帮助理解现阶段最热指标话题 | 引导卖家创建指标商品时对指标的填写把控 |

### 3.3 P2 行为

P2 行为作为辅助入口，默认弱化展示。

| 行为 | 目标 | 说明 |
| --- | --- | --- |
| 联系平台客服 | 解决首次发布疑问 | 仅作为帮助入口，不形成完整客服系统 |
| 查看新手帮助 | 补充说明 | 展示基础帮助文档或规则说明 |

---

## 4. 新手空状态推荐模块

### 4.1 发布第一个指标商品

模块目标：

- 作为新手空状态的主模块。
- 引导卖家创建第一个指标商品。
- 推动卖家进入指标商品草稿创建流程。

核心内容：

- 发布第一个指标商品。
- 需要准备：商品名称、商品品类、核心指标、库存数量、可售吨位、报价方式、附件；价格有效期可按实际经营需要填写。
- 主行为：新建指标商品。

### 4.2 新手经营指引

模块目标：

- 帮助卖家理解首次经营需要完成的步骤。
- 将首次经营拆成可理解的动作。

建议步骤：

- 第一步：填写基础信息。
- 第二步：填写核心指标。
- 第三步：维护库存/吨位。
- 第四步：填写报价；价格有效期可按实际经营需要填写。
- 第五步：上传附件并提交审核。

说明：

- 新手经营指引只说明首次发布路径。
- 不扩展为完整新手任务中心。

### 4.3 高频指标排行

模块目标：

- 帮助卖家理解当前高频指标的热度值和常见填写方式。

展示内容：

- 指标名称。
- 指标热度值。
- 指标高频讨论话题。

说明：

- 高频指标排行只是参考。
- 不自动生成指标。
- 不代替卖家填写。

### 4.4 高频讨论问题

模块目标：

- 帮助卖家理解当前对于指标讨论的问题主要是什么。
- 辅助卖家判断应该如何组织自己的指标商品。

展示内容：

- 高频讨论的问题。
- 问题标签。


说明：

- 高频讨论问题只作为示例和参考。
- 不扩展为 BI 分析。
- 不形成个性化推荐。

### 4.5 平台客服入口

模块目标：

- 在卖家首次发布遇到资料、审核、指标填写问题时，提供帮助入口。

展示内容：

- 联系平台客服。
- 查看发布规范。
- 查看审核要求。

说明：

- 平台客服入口不扩展为完整客服系统。
- 不形成沟通状态机。

### 4.6 新手帮助

模块目标：

- 承接基础规则说明，帮助卖家理解指标商品经营。

展示内容：

- 什么是指标商品。
- 为什么指标优先于商品图片和商品名称。
- 审核通过后买家才能查看。
- 已上架后才能开放询价、议价和 IM 入口。

## 5. 空状态页面结构

新手空状态应复用工作台的基础页面框架，但替换经营态内容。

### 5.1 保留区域

以下区域保留：

- 顶部平台导航。
- 企业身份与认证信息。
- 工作台页面入口。
- 基础帮助入口。

说明：

- 保留这些区域用于维持平台一致性和企业身份识别。
- 不应因为空状态而改变工作台的基础框架。

### 5.2 替换区域

以下区域应替换为空状态引导内容：

| 原区域 | 空状态替换 |
| --- | --- |
| 顶部经营概览区 | 首次经营启动提示 |
| 主经营区 | 发布第一个指标商品模块 |
| 右侧待办/建议区 | 新手经营指引、高频指标排行、高频讨论问题、新手帮助 |

### 5.3 隐藏区域

以下内容在完全空状态下应隐藏：

- 经营数据图表或经营数据总览。
- 商品经营状况数据。
- 待响应沟通消息内容。
- 成交进度跟踪明细。
- 订单、合同、物流、售后明细。
- 库存预警列表。

### 5.4 底部区域

- 商品管理入口：“发布新商品”、“查看全部商品”、“草稿箱”保留
- 账户、物流、合同入口：保留展示入口或说明，无数据为缺省展示。

### 5.5 引导模块布局


1. 首次经营启动提示。
2. 发布第一个指标商品。
3. 新手经营指引。
4. 高频指标排行。
5. 高频讨论问题。
6. 新手帮助 / 平台客服入口。

说明：

- 第一屏必须出现“发布第一个指标商品”。
- 不应让 0 值经营数据占据主视觉区域。
- 不应将订单、合同、物流、账户入口放在新手空状态的主优先级。

---

## 6. 空状态结束条件

当卖家完成首次经营相关动作后，页面应从“新手引导态”切换为对应经营态。

### 6.1 完全结束新手空状态的条件

出现以下任一行为后，应退出完整新手空状态：

- 已创建第一个指标商品草稿。
- 已保存第一个指标商品草稿。
- 已提交第一个指标商品审核。
- 已存在待审核指标商品。
- 已存在审核驳回指标商品。
- 已存在已上架指标商品。
- 已存在已下架指标商品。

### 6.2 切换后的页面状态

| 卖家完成行为 | 页面切换结果 |
| --- | --- |
| 创建但未提交指标商品 | 进入草稿经营处理态 |
| 保存草稿 | 进入草稿箱或草稿处理态 |
| 提交审核 | 进入待审核经营处理态 |
| 审核驳回 | 进入审核驳回处理态 |
| 审核通过并上架 | 进入经营态工作台 |
| 主动下架后无其他商品 | 进入已下架经营处理态，不回到新手空状态 |

说明：

- 新手空状态只适用于卖家从未产生指标商品的初始阶段。
- 一旦产生过指标商品生命周期记录，即使当前没有已上架商品，也不应回到完整新手空状态。

---

## 7. 当前 MVP 不做

当前 MVP 不做：

- 完整成长体系。
- 积分体系。
- 新手任务中心。
- AI 智能运营。
- AI 自动生成指标。
- 个性化推荐。
- 复杂经营分析。
- BI 分析。
- 完整客服系统。
- 完整订单流程。
- 完整合同流程。
- 完整物流履约。
- 完整账户资金管理。
- 指标研究院。
- 多商品组合经营。

说明：

- 新手空状态只服务于首次指标商品经营启动。
- 当前协议不新增业务状态机。
- 当前协议不改变指标商品主状态：草稿、待审核、审核驳回、已上架、已下架。
- 当前协议不扩展库存、沟通、订单、合同、物流或账户状态机。
