## 1. 业务背景分析

大宗 3.0 的核心业务链路围绕“指标驱动交易”展开，平台不是单一商品展示系统，而是由卖家、买家、平台管理员、承运方、资金提供方共同参与的交易协同系统。

现有核心页面包括：

- 卖家工作台
- 指标化商品发布页 / 商品信息编辑页
- 指标表达优化页
- 指标货源列表页
- 指标详情页
- 企业沟通中心 / 指标沟通页 / 询价议价页
- 指标对比页
- 订单确认页 / 订单处理页
- 合同管理页
- 物流服务模块 / 履约跟踪页
- 金融服务页 / 授信申请页 / 资金进度页
- 研究院首页 / 指标讨论页 / 需求实验页
- 拍卖管理页
- 云仓页
- 买家中心页
- 印章管理页
- 平台管理 / 操作日志页

因此必须补充角色权限矩阵，避免后续开发只做页面菜单可见性，而忽略按钮、数据、审批、导出等企业级权限边界。

## 2. 业务目标分析

| 目标 | 说明 |
|---|---|
| 支撑多角色协同 | 明确卖家、买家、平台、承运方、资金方在交易链路中的操作边界 |
| 降低越权风险 | 避免跨企业查看、越权编辑、绕过审批、敏感数据导出 |
| 支撑研发落地 | 为前端按钮控制、后端接口鉴权、菜单配置提供依据 |
| 支撑 QA 验收 | 为权限测试、流程测试、导出测试提供验收口径 |
| 支撑长期扩展 | 后续可扩展到部门权限、岗位权限、数据范围权限、审批流配置 |

## 3. 角色分析

| 角色 | 角色身份 | 核心职责 | 数据范围 | 权限边界 |
|---|---|---|---|---|
| 货主 / 卖家 | 生产型企业、供应商、商品发布方 | 发布商品、维护指标、报价议价、确认订单、上传合同、发起发货 | 本企业商品、订单、合同、会话、资金、物流 | 不可审批平台规则；不可查看其他企业经营数据 |
| 买家企业 / 平台买家 | 工业采购方、终端采购方、贸易采购方 | 浏览货源、筛选指标、询价议价、确认订单、申请金融服务 | 本企业询价、订单、合同、资金申请、沟通记录 | 不可编辑卖家商品；不可查看其他买家交易数据 |
| 平台管理员 | 平台运营、规则、风控、撮合、审核人员 | 商品审核、表达优化、订单异常处理、权限配置、风控审计 | 授权范围内平台数据 | 可审核和运营介入，但不可替代买卖双方确认核心交易条件 |
| 承运方 | 平台物流、专线运输、车队、司机管理方 | 承接运单、更新物流状态、上传回单、处理运输异常 | 被分配的运单、必要订单摘要 | 不可查看完整交易价格和资金明细；不可修改商品、合同核心内容 |
| 资金提供方 | 银行、保理、授信、融资机构 | 授信审批、放款跟踪、回款监控、风险评估 | 被授权的融资申请、合同、订单、企业资料 | 不可修改交易订单；不可绕过平台审批直接放款 |

## 4. 权限口径定义

| 权限项 | 定义 | 前端控制 | 后端控制 |
|---|---|---|---|
| 查看 | 是否可进入页面、查看列表、查看详情 | 菜单、路由、页面区块显示 | 接口鉴权、租户隔离、字段脱敏 |
| 编辑 | 是否可新增、修改、删除、提交、上传、发送业务数据 | 按钮启用/禁用、表单只读 | 接口动作权限、状态校验、数据归属校验 |
| 审批 | 是否可审核、驳回、确认、风控放行、运营介入 | 审批按钮显示 | 审批流节点、角色权限、操作日志 |
| 导出 | 是否可导出列表、明细、报表、附件 | 导出按钮显示 | 导出权限、字段脱敏、水印、导出日志 |

权限标记：

- `允许`：该角色默认具备该权限。
- `条件允许`：满足数据范围、状态、审批节点或授权条件后具备。
- `只读`：仅查看，不允许业务操作。
- `禁止`：不具备权限。

## 8. 风险分析

| 风险点 | 典型场景 | 控制措施 |
|---|---|---|
| 越权查看 | 买家查看其他企业订单、卖家查看其他货主报价 | 租户隔离、订单归属校验、接口鉴权 |
| 越权编辑 | 平台运营直接修改买卖双方交易价格 | 核心交易字段仅交易双方确认，平台只能备注或发起审批 |
| 审批绕过 | 商品未审核直接上架、合同未签直接发货 | 状态机强校验，后端禁止非法状态流转 |
| 导出泄露 | 导出全平台订单、资金、合同 | 导出权限单独配置、字段脱敏、水印、导出日志 |
| 并发冲突 | 多买家同时下单导致超卖 | 库存锁定、幂等提交、事务校验 |
| 重复提交 | 重复报价、重复转订单、重复发货 | 幂等键、按钮 loading、防重复接口 |
| 金融风险 | 未授权资金方查看合同或放款 | 授权链路、资金方数据范围、审批记录 |
| 物流数据错配 | 承运方更新非本方运单 | 运单分配校验、承运方角色隔离 |

## 9. QA 验收标准

### 9.1 功能验收

| 验收项 | 标准 |
|---|---|
| 页面权限 | 不同角色登录后仅能看到授权菜单和页面 |
| 按钮权限 | 无权限按钮不展示或禁用，且后端接口同样拒绝 |
| 数据权限 | 用户只能查看本企业、本机构或授权范围数据 |
| 审批权限 | 仅当前审批节点角色可审批 |
| 导出权限 | 仅有导出权限的角色可导出，导出内容符合脱敏规则 |
| 审计日志 | 查看敏感数据、编辑、审批、导出均有日志 |

### 9.2 测试场景

| 类型 | 测试场景 |
|---|---|
| 正常流程 | 卖家发布商品 -> 平台审核 -> 买家询价 -> 卖家报价 -> 买家确认 -> 订单 -> 合同 -> 物流 |
| 异常流程 | 商品驳回、报价过期、订单取消、合同作废、物流异常、金融驳回 |
| 权限场景 | 五类角色分别访问全部页面，验证菜单、按钮、数据、导出权限 |
| 边界场景 | 跨企业数据访问、无审批节点审批、无导出权限导出、状态不允许编辑 |
| 并发场景 | 多买家同时询价/下单、卖家重复提交发布、承运方重复更新物流 |
| 状态流转场景 | 待审核不能上架前展示给买家；已关闭会话不能报价；已完成订单不能取消 |
| 回归场景 | 权限配置调整后，历史订单、合同、会话、物流、资金页面权限不受破坏 |
