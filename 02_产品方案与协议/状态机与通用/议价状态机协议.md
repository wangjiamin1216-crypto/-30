# 议价状态机协议

## 1. 状态机对象说明

本状态机对象是：**议价沟通单**。

议价沟通单是买家基于已上架指标商品发起询价、议价后，买卖双方围绕价格、指标参数、采购量、交货地、交付方式和备注进行结构化协商的业务对象。

本状态机不定义：

- 卖家指标商品主状态机。
- 库存状态机。
- 订单完整状态机。
- 合同、物流、履约、金融状态机。

议价沟通单必须关联：

- 指标商品 ID。
- 指标商品状态版本号。
- 买家企业 ID。
- 卖家企业 ID。
- 企业沟通会话 ID。

议价沟通单只能在指标商品满足以下条件时被新建：

- 指标商品当前状态为 `已上架`。
- 指标商品允许询价或允许议价。
- 买家企业具备查看和发起沟通权限。

## 3. 每个状态的定义

### 3.1 草稿

草稿表示买家已从商品列表页、商品详情页或企业沟通中心打开询价/议价表单，但尚未正式提交给卖家。

业务含义：

- 买家可填写或修改期望价格、期望调整指标参数、采购量、交货地、交付方式、备注等信息。
- 草稿只对买家自身可见。
- 草稿不生成卖家待办。
- 草稿不通知卖家。
- 草稿不锁定价格、库存或可售吨位。

### 3.2 待卖家响应

待卖家响应表示买家已提交询价/议价，议价沟通单进入卖家处理阶段。

业务含义：

- 卖家可查看买家提交的表单式询价/议价卡。
- 卖家可接受、拒绝或修改议价方案。
- 买家可在卖家处理前撤回。
- 系统应生成卖家待响应提醒。

### 3.3 卖家已修改

卖家已修改表示卖家未直接接受买家原始诉求，而是给出修改后的价格、指标参数、采购量、交货地、交付方式或备注方案。

业务含义：

- 卖家修改的是议价沟通单中的回复方案，不是指标商品主字段。
- 卖家修改必须生成新的卖家回复卡。
- 卖家修改不得覆盖买家原始议价诉求。
- 卖家修改后应进入待买家确认。

### 3.4 待买家确认

待买家确认表示卖家已给出修改方案，等待买家确认是否接受。

业务含义：

- 买家可接受卖家方案，使议价成功。
- 买家可拒绝卖家方案，使议价终止。
- 买家可继续发起新一轮议价诉求。
- 超过有效期未确认，可进入已失效。

### 3.5 议价成功

议价成功表示买卖双方已确认本次交易意向中的核心内容。

必须确认的信息包括：

- 最终价格。
- 价格单位。
- 采购量。
- 交货地。
- 交付方式。
- 成交指标参数或指标容差口径。
- 备注和附加条款。

业务含义：

- 系统固化最终议价快照。
- 生成议价成功系统状态卡。
- 卖家可基于该快照发起订单成交。
- 买家和卖家均不可再修改该轮议价结果。

### 3.6 已拒绝

已拒绝表示卖家拒绝买家原始诉求，或买家拒绝卖家修改后的方案。

业务含义：

- 拒绝后当前议价沟通单终止。
- 必须记录拒绝方、拒绝原因和拒绝时间。
- 已拒绝后不可继续修改或确认。
- 如商品仍已上架且入口开放，买家可重新发起新的议价沟通单。

### 3.7 已撤回

已撤回表示买家主动撤回已提交但尚未终态的议价沟通单。

业务含义：

- 只有买家可撤回自己发起的议价沟通单。
- 已议价成功、已拒绝、已失效、已转订单不可撤回。
- 撤回后卖家不可继续处理该议价单。
- 必须记录撤回原因和撤回时间。

### 3.8 已失效

已失效表示议价沟通单因超时、指标商品状态变化、价格有效期失效且未重新确认、入口关闭或权限变化而不可继续。

业务含义：

- 已失效后不可继续编辑、接受、拒绝或转订单。
- 历史沟通记录和表单快照仍可按权限查看。
- 如需继续沟通，需基于最新指标商品状态重新发起。

### 3.9 已转订单

已转订单表示卖家已基于议价成功结果发起订单成交。

业务含义：

- 只能由议价成功流转而来。
- 生成订单发起卡。
- 订单后续由订单业务域承接。
- 议价结果不可再修改。
- 议价沟通单作为订单来源可追溯。

## 4. 触发动作、操作人、前置条件、后置结果

| 原状态 | 触发动作 | 操作人 | 前置条件 | 新状态 | 后置结果 |
| --- | --- | --- | --- | --- | --- |
| 无 | 打开询价/议价表单 | 买家 | 指标商品已上架；买家有权限；允许询价或议价 | 草稿 | 生成草稿，仅买家可见 |
| 草稿 | 保存草稿 | 买家 | 草稿字段合法 | 草稿 | 更新草稿版本，不通知卖家 |
| 草稿 | 放弃草稿 | 买家 | 草稿未提交 | 无状态或草稿废弃 | 删除或标记废弃草稿，不进入卖家侧 |
| 草稿 | 提交询价/议价 | 买家 | 采购量、交货地等必填项完整；状态版本号有效；商品仍已上架 | 待卖家响应 | 生成询价/议价卡；通知卖家；记录状态日志 |
| 待卖家响应 | 卖家接受 | 卖家 | 卖家有权限；议价单未过期；商品仍可交易 | 议价成功 | 固化最终快照；生成成功状态卡 |
| 待卖家响应 | 卖家拒绝 | 卖家 | 卖家有权限；填写拒绝原因 | 已拒绝 | 生成拒绝状态卡；议价终止 |
| 待卖家响应 | 卖家修改方案 | 卖家 | 卖家有权限；填写修改后的价格、吨位、指标或交付方案 | 卖家已修改 | 生成卖家回复卡；版本号递增 |

| 待买家确认 | 买家拒绝方案 | 买家 | 买家有权限；填写拒绝原因 | 已拒绝 | 生成拒绝状态卡；议价终止 |
| 待买家确认 | 买家继续议价 | 买家 | 买家有权限；填写新一轮诉求；商品仍可交易 | 待卖家响应 | 生成新版本议价卡；通知卖家 |
| 待卖家响应 | 买家撤回 | 买家 | 买家为发起方；卖家尚未接受；未终态 | 已撤回 | 生成撤回状态卡；卖家不可继续处理 |
| 卖家已修改 | 买家撤回 | 买家 | 买家为发起方；未终态 | 已撤回 | 生成撤回状态卡 |
| 待买家确认 | 买家撤回 | 买家 | 买家为发起方；未终态 | 已撤回 | 生成撤回状态卡 |
| 待卖家响应 | 超时失效 | 系统 | 超过议价有效期且卖家未响应 | 已失效 | 生成失效状态卡 |
| 待买家确认 | 超时失效 | 系统 | 超过卖家回复有效期且买家未确认 | 已失效 | 生成失效状态卡 |
| 待卖家响应/卖家已修改/待买家确认 | 商品不可交易 | 系统 | 商品下架、入口关闭、权限失效或状态版本失效 | 已失效 | 终止新增协商，保留历史 |
| 议价成功 | 发起订单成交 | 卖家 | 最终快照完整；卖家有权限；未重复转订单 | 已转订单 | 生成订单发起卡；传递订单来源数据 |

## 6. 异常流转

异常流转不新增主状态，只通过已失效、已拒绝、已撤回等终态承接。

| 异常类型 | 可能出现状态 | 触发条件 | 目标状态 | 处理规则 |
| --- | --- | --- | --- | --- |
| 指标商品下架 | 待卖家响应、卖家已修改、待买家确认 | 关联指标商品从已上架变为已下架 | 已失效 | 阻断继续协商，保留历史记录 |
| 询价/议价入口关闭 | 待卖家响应、卖家已修改、待买家确认 | 商品不再允许询价或议价 | 已失效 | 阻断继续处理 |
| 价格有效期失效 | 待卖家响应、待买家确认 | 报价或卖家回复方案超过有效期 | 已失效 | 提示需基于最新价格重新发起 |
| 状态版本过期 | 草稿、待卖家响应、待买家确认 | 提交时指标商品状态版本号与服务端不一致 | 已失效或阻断提交 | 草稿阶段阻断提交；已提交阶段可置为已失效 |
| 买家权限失效 | 草稿、待卖家响应、待买家确认 | 买家企业无权继续操作 | 已失效 | 记录权限异常 |
| 卖家权限失效 | 待卖家响应、卖家已修改 | 卖家企业或操作人无权继续处理 | 已失效 | 记录权限异常 |
| 可售吨位不足 | 草稿、待卖家响应、待买家确认 | 买家采购量超过最新可承诺范围 | 阻断提交或已失效 | 提示重新确认采购量 |
| 最小起售不满足 | 草稿 | 买家采购量低于最小起售数量 | 草稿 | 阻断提交，提示修正 |
| 重复提交 | 草稿 | 同一买家同一商品短时间重复提交相同内容 | 草稿或待卖家响应 | 阻断或提示复用已有议价单 |
| 终态后操作 | 已拒绝、已撤回、已失效、已转订单 | 用户尝试继续修改、确认或拒绝 | 原状态不变 | 拒绝操作并记录异常日志 |
| 订单重复发起 | 已转订单 | 卖家重复点击发起订单成交 | 已转订单 | 拒绝重复发起，返回已有订单来源 |

## 7. 买家可见状态

| 状态 | 买家是否可见 | 买家可执行动作 |
| --- | --- | --- |
| 草稿 | 是 | 编辑、保存、提交、放弃 |
| 待卖家响应 | 是 | 查看、撤回、补充文本说明 |
| 卖家已修改 | 是 | 查看卖家回复、撤回、等待确认 |
| 待买家确认 | 是 | 确认方案、拒绝方案、继续议价、撤回 |
| 议价成功 | 是 | 查看最终快照、查看订单发起记录 |
| 已拒绝 | 是 | 查看拒绝原因、重新发起新议价 |
| 已撤回 | 是 | 查看撤回记录、重新发起新议价 |
| 已失效 | 是 | 查看失效原因、基于最新商品重新发起 |
| 已转订单 | 是 | 查看订单发起卡、查看议价来源记录 |

买家可见性规则：

- 买家只能查看本企业相关议价沟通单。
- 买家可查看完整历史沟通记录和表单快照。
- 买家不得查看其他买家企业的议价记录。
- 买家不得修改卖家回复卡和订单发起卡。

| 状态 | 卖家是否可见 | 卖家可执行动作 |
| --- | --- | --- |
| 草稿 | 否 | 无 |
| 待卖家响应 | 是 | 查看、接受、拒绝、修改方案、补充文本说明 |
| 卖家已修改 | 是 | 查看卖家回复、等待买家确认、补充文本说明 |
| 待买家确认 | 是 | 查看、等待买家确认、补充文本说明 |
| 议价成功 | 是 | 查看最终快照、发起订单成交 |
| 已拒绝 | 是 | 查看拒绝原因、查看历史记录 |
| 已撤回 | 是 | 查看撤回记录 |

卖家可见性规则：

- 卖家只能查看本企业作为供应方的议价沟通单。
- 卖家不可查看买家未提交的草稿。
- 卖家不得修改买家原始询价/议价表单。
- 卖家只能追加回复方案或补充说明。

## 9. 终态规则

以下状态为终态或完成后承接状态：

- 已拒绝。
- 已撤回。
- 已失效。
- 已转订单。

终态规则：

- 终态后不得继续修改当前议价沟通单。
- 终态后不得覆盖历史表单卡片。
- 终态后不得删除状态日志。
- 如需继续沟通，应新建议价沟通单。

议价成功不是终态，而是完成状态：

- 议价成功后仍允许卖家发起订单成交。
- 议价成功后不允许修改最终议价快照。
- 议价成功后如双方需要修改条件，应新建新一轮议价。

## 10. 状态日志要求

每次状态变化必须记录状态日志。

状态日志字段：

- 议价沟通单 ID。
- 指标商品 ID。
- 指标商品状态版本号。
- 买家企业 ID。
- 卖家企业 ID。
- 会话 ID。
- 操作人。
- 操作人角色。
- 操作时间。
- 原状态。
- 新状态。
- 触发动作。
- 操作原因。
- 当前议价版本号。
- 关联消息 ID。
- 关联表单卡片 ID。
- 备注。

状态日志规则：

- 日志只能追加，不得覆盖。
- 买家原始诉求不得被卖家覆盖。
- 卖家回复方案不得被买家覆盖。
- 表单卡片每次修改必须生成新版本。
- 系统自动失效必须记录触发规则。
- 已转订单必须记录订单来源和订单业务域返回的订单标识。

## 11. 协议结论

议价状态机以议价沟通单为对象，承接买家从列表页、详情页或企业沟通中心发起的表单式询价/议价。

该状态机允许买卖双方围绕价格、指标参数、采购量、交货地和备注形成可追溯协商过程，并在议价成功后由卖家发起订单成交。

该状态机不改变指标商品主状态，不定义库存状态机，不定义订单完整状态机。所有状态变化必须可见、可追踪、可审计。
