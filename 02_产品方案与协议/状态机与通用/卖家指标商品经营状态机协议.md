# 卖家指标商品经营状态机协议

---

## 1. 状态机对象说明

本状态机对象是：**指标商品**。

指标商品是卖家围绕某一商品载体配置的一组可交易指标、经营信息、库存信息与询价/议价沟通入口，是卖家指标经营工作台中真正具备生命周期的业务对象。

卖家指标经营工作台只是页面容器，不是状态机对象。库存当前只是指标商品的经营字段和风险标签，不独立成为库存状态机。沟通当前只保留询价/议价入口、待办提醒和 IM 进入能力，不独立成为沟通状态机。

结构协议中的成交进度、同类指标商品销售排行、账户、物流、合同等内容，只作为卖家经营工作台的辅助入口、聚合信息或经营提醒，不进入指标商品主状态机。

---

## 2. 状态列表
指标商品主状态只包含以下 5 个状态：

| 状态 | 状态类型 | 是否可被买家查看 | 是否可发起议价 |
| --- | --- | --- | --- |
| 草稿 | 初始状态 | 否 | 否 |
| 待审核 | 中间状态 | 否 | 否 |
| 审核驳回 | 异常回退状态 | 否 | 否 |
| 已上架 | 生效状态 | 是 | 是 |
| 已下架 | 终止/暂停经营状态 | 否 | 否 |

---

## 3. 每个状态的业务含义

### 3.1 草稿

草稿表示指标商品已创建，但尚未提交平台审核。该状态下，指标商品只对卖家自身可见，用于补充或修改指标、库存、价格、图片、附件、说明等经营信息。

草稿不是可交易状态，不进入买家搜索、推荐、详情、询价/议价或交易链路。

### 3.2 待审核

待审核表示卖家已提交指标商品，等待平台审核。该状态下，指标商品内容应被冻结为待审核版本，平台基于指标完整性、商品合规性、经营信息真实性、附件有效性等规则进行审核。

待审核不是可交易状态，不对买家展示，不允许买家发起议价。

### 3.3 审核驳回

审核驳回表示平台审核未通过，指标商品需要卖家根据审核意见修改后重新提交。该状态是从待审核回退形成的异常回退状态。

审核驳回不是可交易状态，不对买家展示。系统必须保留驳回原因、审核意见和驳回时间，便于卖家修正。

### 3.4 已上架

已上架表示指标商品已通过平台审核并正式进入经营状态。该状态下，指标商品可以被买家查看，可以进入搜索、列表、详情、询价、议价和成交推进链路。

已上架是唯一允许买家发起议价、询价的主状态。

### 3.5 已下架

已下架表示指标商品已经停止当前经营，可以由卖家主动下架、平台强制下架、平台规则触发下架或经营条件失效触发下架。

已下架不是可交易状态，不对买家继续开放新的询价/议价入口。历史沟通记录、历史订单和历史合同可通过对应业务域追溯，但本状态机不展开订单、合同或履约状态；不允许基于该指标商品发起新的询价/议价。

---

## 4. 状态流转规则

### 4.1 总体流转

草稿
  -> 提交审核
  -> 待审核
  -> 审核通过
  -> 已上架

待审核
  -> 审核不通过
  -> 审核驳回
  -> 修改后重新提交
  -> 待审核

待审核
  -> 撤回审核
  -> 草稿

已上架
  -> 卖家主动下架 / 平台强制下架 / 平台规则下架 / 经营条件失效
  -> 已下架

已下架
  -> 编辑并重新提交审核
  -> 待审核

### 4.2 草稿进入待审核

草稿可以由卖家提交审核后进入待审核。

流转条件：

- 指标商品基础信息已填写完整。
- 核心指标、指标值、指标单位、指标说明满足提交要求。
- 商品经营信息已填写完整，包括报价方式、报价金额、价格单位、库存数量、可售吨位、生产区域、交付区域、交易方式、交付方式、最小起售数量等当前 MVP 必要字段；价格有效期如填写，必须满足字段校验规则。
- 必要附件、图片或资质材料已上传。
- 当前卖家具备提交该指标商品的权限。
- 指标商品不存在未解决的数据异常或必填项缺失。

流转结果：

- 原状态：草稿。
- 新状态：待审核。
- 生成一条提交审核状态日志。
- 锁定待审核版本，避免审核期间内容被无记录修改。

### 4.2.1 待审核撤回至草稿

待审核状态可以由卖家撤回审核后回到草稿状态。

流转条件：

- 当前状态必须为待审核。
- 平台尚未完成审核通过或审核驳回。
- 当前卖家具备撤回该指标商品审核的权限。
- 请求状态版本号必须与系统最新状态版本号一致。

流转结果：

- 原状态：待审核。
- 新状态：草稿。
- 原待审核版本失效。
- 卖家可以继续编辑基础字段、指标字段和经营字段。
- 生成一条撤回审核状态日志。

撤回规则：

- 如平台已经完成审核，撤回审核必须失败。
- 撤回后再次提交审核时，应生成新的待审核版本。
- 撤回审核不得删除原提交审核记录和状态日志。

### 4.3 待审核进入已上架

待审核可以由平台审核通过后进入已上架。

流转条件：

- 平台审核通过指标商品信息。
- 指标内容、商品信息、经营信息、附件材料均符合平台规则。
- 卖家账号、企业资质、经营权限处于有效状态。
- 指标商品不存在平台要求必须阻断上架的风险。

流转结果：

- 原状态：待审核。
- 新状态：已上架。
- 指标商品正式对买家可见。
- 买家可以查看该指标商品并发起询价、议价。
- 生成一条审核通过状态日志。

### 4.4 待审核进入审核驳回

待审核可以由平台审核不通过后进入审核驳回。

流转条件：

- 平台审核发现指标、商品、经营、附件、资质或合规信息不满足要求。
- 平台审核人员必须填写审核意见。
- 如存在多项驳回原因，应记录主要原因和补充说明。

流转结果：

- 原状态：待审核。
- 新状态：审核驳回。
- 指标商品仍不可被买家查看。
- 卖家可以查看驳回原因并修改后重新提交。
- 生成一条审核驳回状态日志。

### 4.5 审核驳回重新提交

审核驳回可以由卖家修改后重新提交进入待审核。

流转条件：

- 卖家已查看或处理驳回原因。
- 卖家已完成必要修改。
- 修改后的指标商品满足提交审核的完整性要求。
- 当前卖家具备重新提交权限。

流转结果：

- 原状态：审核驳回。
- 新状态：待审核。
- 生成新的待审核版本。
- 保留历史驳回记录，不覆盖原审核意见。
- 生成一条重新提交状态日志。

### 4.6 已上架进入已下架

已上架可以进入已下架。

触发方式：

- 卖家主动下架。
- 平台因该企业违规、资质失效、信息异常等原因强制下架。
- 平台规则触发自动下架。
- 经营条件失效，例如可售吨位为 0 且卖家未及时补充库存，或商品经营期限到期。

流转条件：

- 卖家主动下架时，操作人必须具备下架权限。
- 平台强制下架时，必须填写下架原因。
- 自动下架时，系统必须记录触发规则。
- 如存在未完成订单，状态流转不得删除或覆盖历史交易记录；订单、合同、物流和结算由对应业务域继续处理，本状态机不展开这些流程。

流转结果：

- 原状态：已上架。
- 新状态：已下架。
- 指标商品不再对买家开放询价、议价。
- 既有历史沟通记录和历史交易记录仍可查看和追溯。
- 生成一条下架状态日志。

### 4.7 已下架重新提交

已下架可以由卖家编辑后重新提交审核进入待审核。

流转条件：

- 卖家确认重新经营该指标商品。
- 卖家完成必要的指标、报价、库存、可售吨位、附件或经营信息更新；价格有效期如填写，必须满足字段校验规则。
- 当前卖家具备重新提交权限。
- 指标商品满足提交审核的完整性要求。

流转结果：

- 原状态：已下架。
- 新状态：待审核。
- 生成新的待审核版本。
- 已下架原因和历史经营记录保留。
- 生成一条重新提交状态日志。

## 5. 每个状态允许的行为

| 状态 | 允许行为 |
| --- | --- |
| 草稿 | 编辑指标商品；保存草稿；修改指标；修改经营信息；修改库存数量；修改可售吨位；上传或删除附件；提交审核；删除草稿 |
| 待审核 | 查看待审核内容；查看提交记录；撤回审核；查看审核进度；联系平台处理审核问题 |
| 审核驳回 | 查看驳回原因；查看审核意见；编辑指标商品；修改指标；修改经营信息；修改库存数量；修改可售吨位；上传或替换附件；保存修改；重新提交审核 |
| 已上架 | 查看经营信息；查看商品经营状况；修改不影响审核主版本的经营信息；调整库存数量；调整可售吨位；查看库存预警；查看待响应数量；进入最新询价、议价消息；进入 IM；查看成交进度入口；下架 |
| 已下架 | 查看历史信息；查看下架原因；查看历史沟通记录；编辑后重新提交审核；保留历史记录 |

说明：

- 已上架后的经营信息修改仅限当前 MVP 允许的经营字段，例如库存数量、可售吨位、部分价格或交付说明等。若修改内容影响核心指标、合规信息或审核主版本，应重新进入审核流程。
- IM 企业沟通相关能力在本协议中只表现为入口、数量和最新沟通消息提醒，不形成独立沟通状态机。
- 商品售卖次数、商品售卖总量、商品售卖总额、被查看次数、买家近期关注指标、上次成交买家、成交最多买家等商品经营状况信息，只作为系统统计和经营参考，不触发指标商品主状态变化。
- 成交进度跟踪只作为工作台辅助入口，不定义订单、合同、物流、售后或履约状态机。

## 6. 每个状态允许的按钮

本节只定义业务动作入口，不定义 UI 样式、布局或视觉呈现。

| 状态 | 允许按钮 |
| --- | --- |
| 草稿 | 编辑；保存；提交审核；删除 |
| 待审核 | 查看；撤回审核；查看审核进度 |
| 审核驳回 | 查看驳回原因；编辑；保存；重新提交 |
| 已上架 | 查看；修改经营信息；调整库存/吨位；进入 IM；下架 |
| 已下架 | 查看；查看下架原因；编辑；重新提交 |

按钮出现规则：

- 按钮必须受状态、角色、权限共同约束。
- 没有对应状态权限的按钮不得出现或不得可执行。
- 同一指标商品在并发操作下，应以服务端最新状态为准。
- 状态已变化后，旧状态按钮触发的动作必须被拒绝并记录异常。

### 6.1 删除草稿规则

删除草稿只允许在草稿状态下执行。

规则：

- 删除草稿前必须确认当前状态仍为草稿。
- 删除草稿必须校验操作人权限。
- 删除草稿采用逻辑删除，不做物理删除。
- 删除后该草稿不再出现在卖家工作台、全部商品管理页和草稿箱的默认列表中。
- 删除草稿必须记录操作日志或异常日志。

禁止：

- 不允许删除待审核商品。
- 不允许删除审核驳回商品。
- 不允许删除已上架商品。
- 不允许删除已下架商品。
- 不允许删除历史沟通、历史订单、历史合同或历史经营记录。

## 7. 每个状态禁止的操作

| 状态 | 禁止操作 |
| --- | --- |
| 草稿 | 不可被买家查看；不可被买家搜索；不可进入买家推荐；不可发起询价、议价；不可进入新增交易链路 |
| 待审核 | 不可被买家查看；不可被买家搜索；不可进入买家推荐；不可发起询价、议价；不可直接修改待审核版本；不可绕过审核上架 |
| 审核驳回 | 不可被买家查看；不可被买家搜索；不可进入买家推荐；不可发起询价、议价；不可直接上架；不可忽略审核意见直接生效 |
| 已上架 | 不可绕过权限下架；不可无日志修改核心指标；不可在库存不足且触发阻断规则时继续新增可售承诺；不可删除历史沟通、订单、合同记录 |
| 已下架 | 不可被买家发起询价、议价；不可进入买家新增交易链路；不可直接恢复已上架；不可删除下架原因；不可删除历史经营记录 |

说明：

- 已上架状态下允许查看成交进度、订单、合同、物流或售后相关入口，但这些入口不得反向改变指标商品主状态。
- 账户、物流、合同等辅助入口不得绕过指标商品状态规则开放新的询价、议价或经营承诺。

## 8. 异常状态与处理规则

异常状态不进入主状态列表，只作为指标商品在某一主状态下的风险标签、阻断原因或处理标记。

| 异常类型 | 可能出现的主状态 | 触发条件 | 处理规则 |
| --- | --- | --- | --- |
| 资料缺失 | 草稿、审核驳回 | 必填指标、经营信息、附件或资质缺失 | 阻断提交审核，提示卖家补齐资料 |
| 审核超时 | 待审核 | 超过平台承诺审核时限仍未审核完成 | 生成审核待办提醒，允许卖家查看进度或联系平台 |
| 审核驳回 | 审核驳回 | 平台审核不通过 | 保留驳回原因和审核意见，允许卖家修改后重新提交 |
| 库存预警 | 草稿、审核驳回、已上架、已下架 | 库存数量或可售吨位低于预警阈值 | 仅作为经营风险标签，不改变主状态 |
| 库存不足 | 已上架 | 可售吨位为 0 或低于平台允许继续承诺的最低值 | 可触发经营提醒；必要时按平台规则自动下架 |
| 权限异常 | 全部状态 | 操作人无权执行当前动作 | 拒绝操作并记录异常日志 |
| 非法流转 | 全部状态 | 请求的原状态与系统最新状态不一致，或目标状态不符合流转规则 | 拒绝流转并记录异常日志 |
| 并发冲突 | 全部状态 | 多个操作同时修改同一指标商品状态或关键字段 | 以最新版本为准，拒绝过期操作并记录冲突 |
| 平台强制下架 | 已上架 | 违规、资质失效、投诉、风控或平台规则命中 | 流转至已下架，并记录强制下架原因 |

异常处理原则：

- 异常标签不得新增主状态。
- 异常标签不得绕过主状态流转规则。
- 异常必须可记录、可追踪、可回溯。
- 阻断类异常必须明确阻断原因和恢复条件。

## 9. 库存预警逻辑

库存当前不进入指标商品主状态机，只作为指标商品的经营字段和风险标签。

库存相关字段包括：

- 库存数量。
- 可售吨位。
- 库存预警标签。

库存预警判断：

| 预警标签 | 触发条件 | 对主状态影响 | 经营处理 |
| --- | --- | --- | --- |
| 库存正常 | 可售吨位高于预警阈值 | 不影响主状态 | 正常经营 |
| 库存偏低 | 可售吨位大于 0 且低于预警阈值 | 不影响主状态 | 提醒卖家补充库存或调整可售吨位 |
| 库存不足 | 可售吨位等于 0，或低于平台允许继续承诺的最低值 | 默认不改变主状态；如平台规则要求，可触发自动下架 | 阻止新增可售承诺，提醒卖家补充库存或下架 |
| 库存异常 | 库存数量、可售吨位出现负数、不一致或超过可经营范围 | 不直接改变主状态；可阻断提交审核或阻断经营修改 | 要求卖家修正，必要时触发平台审核或风控处理 |

库存预警规则：

- 草稿状态下，库存异常可阻断提交审核。
- 待审核状态下，库存字段属于待审核版本的一部分，审核期间不得无记录修改。
- 审核驳回状态下，卖家可根据驳回意见修正库存数量和可售吨位。
- 已上架状态下，库存偏低或库存不足应形成经营提醒。
- 已上架状态下，可售吨位为 0 时默认不自动下架，应先形成库存不足提醒，提示卖家补充库存、调整可售吨位或主动下架。
- 已上架状态下，如平台规则明确要求可售吨位为 0 不得继续经营，可以自动或人工触发下架，主状态流转为已下架，并记录平台规则来源。
- 已下架状态下，库存预警仅作为历史经营信息和重新提交前的校验条件。

## 10. 状态版本号与并发控制

指标商品必须维护状态版本号，用于处理并发修改、重复提交和非法状态流转。

### 10.1 状态版本号更新时机

以下动作必须更新状态版本号：

- 保存草稿。
- 提交审核。
- 撤回审核。
- 审核通过。
- 审核驳回。
- 审核驳回后重新提交。
- 已下架后重新提交。
- 卖家主动下架。
- 平台强制下架。
- 系统规则触发下架。
- 修改影响审核主版本的关键字段。

### 10.2 并发控制规则

规则：

- 前端提交状态操作时，必须携带当前状态和状态版本号。
- 服务端必须校验请求原状态、目标状态和状态版本号。
- 如果请求状态版本号与系统最新状态版本号不一致，必须拒绝操作。
- 如果请求目标状态不符合状态流转规则，必须拒绝操作。
- 被拒绝的并发冲突、非法流转和过期版本操作必须记录异常日志。

示例：

| 场景 | 处理规则 |
| --- | --- |
| 卖家打开草稿编辑页后，另一操作人已提交审核 | 保存或提交失败，提示状态已变化 |
| 平台审核时，卖家已撤回审核 | 审核失败，提示待审核版本已失效 |
| 平台强制下架后，卖家继续点击下架 | 操作失败，提示系统状态已变化 |

## 11. 状态日志要求

每次状态变化必须记录状态日志。

状态日志必须包含：

- 操作人。
- 操作人角色。
- 操作时间。
- 指标商品 ID。
- 原状态。
- 新状态。
- 操作类型。
- 操作原因。
- 审核意见。
- 备注。
- 触发来源：卖家、平台审核、平台规则、系统自动任务。
- 状态版本号。

不同状态流转的日志要求：

| 状态流转 | 必填日志信息 |
| --- | --- |
| 草稿 -> 待审核 | 操作人、操作时间、原状态、新状态、提交原因、提交版本、备注 |
| 待审核 -> 草稿 | 操作人、操作时间、原状态、新状态、撤回原因、状态版本号、备注 |
| 待审核 -> 已上架 | 审核人、审核时间、原状态、新状态、审核意见、审核结果、备注 |
| 待审核 -> 审核驳回 | 审核人、审核时间、原状态、新状态、驳回原因、审核意见、备注 |
| 审核驳回 -> 待审核 | 操作人、操作时间、原状态、新状态、修改说明、重新提交原因、备注 |
| 已上架 -> 已下架 | 操作人或触发来源、操作时间、原状态、新状态、下架原因、备注 |
| 已下架 -> 待审核 | 操作人、操作时间、原状态、新状态、重新经营原因、提交版本、备注 |

异常日志必须记录：

- 异常类型。
- 触发状态。
- 触发动作。
- 操作人。
- 操作时间。
- 失败原因。
- 系统最新状态。
- 请求目标状态。
- 处理结果。

日志原则：

- 状态日志不得被删除。
- 审核意见不得被覆盖，只能追加。
- 自动流转必须记录触发规则。
- 平台强制操作必须记录平台操作人或系统规则来源。
- 状态日志应支持按指标商品追溯完整生命周期。

### 11.1 状态日志数据结构

状态日志建议至少包含：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 日志 ID | 是 | 状态日志唯一标识 |
| 指标商品 ID | 是 | 被操作的指标商品 |
| 操作人 ID | 是 | 执行动作的用户 |
| 操作人名称 | 否 | 操作人展示名称 |
| 操作人角色 | 是 | 卖家、平台审核人员、平台管理员或系统 |
| 操作时间 | 是 | 状态变化发生时间 |
| 原状态 | 是 | 操作前状态 |
| 新状态 | 是 | 操作后状态 |
| 操作类型 | 是 | 提交审核、撤回审核、审核通过、审核驳回、重新提交、下架等 |
| 操作原因 | 条件必填 | 下架、撤回、强制下架等需要原因 |
| 审核意见 | 条件必填 | 审核相关流转记录 |
| 备注 | 否 | 补充说明 |
| 触发来源 | 是 | 卖家、平台审核、平台规则、系统自动任务 |
| 状态版本号 | 是 | 操作后的最新状态版本号 |

### 11.2 异常日志数据结构

异常日志建议至少包含：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 异常日志 ID | 是 | 异常日志唯一标识 |
| 指标商品 ID | 是 | 被操作的指标商品 |
| 异常类型 | 是 | 权限异常、非法流转、并发冲突、资料缺失等 |
| 触发状态 | 是 | 异常发生时系统状态 |
| 触发动作 | 是 | 触发异常的操作 |
| 操作人 ID | 是 | 触发异常的操作人 |
| 操作时间 | 是 | 异常发生时间 |
| 请求原状态 | 否 | 前端或调用方提交的原状态 |
| 请求目标状态 | 否 | 前端或调用方请求的目标状态 |
| 系统最新状态 | 是 | 服务端最新状态 |
| 请求版本号 | 否 | 调用方提交的版本号 |
| 系统最新版本号 | 是 | 服务端最新版本号 |
| 失败原因 | 是 | 拒绝操作的原因 |
| 处理结果 | 是 | 已拒绝、已提示刷新、已记录等 |
