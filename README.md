# 大宗 3.0 文件归档索引

这个文件夹已按“用途 + 项目重点”重新整理，优先服务日常查找、汇报、评审和继续产出。

## 目录说明

- `00_项目总览与重点/`：项目总览、核心方法、角色卡片、项目介绍、关键展示材料和新账号快速接手说明。
- `01_会议与决策/`：董事长会议纪要、会议录音、访谈截图和会议分析材料。
- `02_产品方案与协议/`：PRD、权限矩阵、页面协议、状态机和业务规则。
- `03_原型与页面/`：可打开查看的 HTML 原型页，按买家、卖家、平台后台等角色拆分。
- `04_设计稿与截图/`：PNG 截图、页面状态图、海报和项目展示图片。
- `05_调研与竞品/`：竞品分析、平台分析和调研访谈提纲。
- `06_AI工作流与方法/`：AI 产品设计工作流、培训话术、过程对话和演讲材料。
- `07_计划与汇报/`：月度规划、功能清单、汇报思路和阶段性交付文档。
- `99_临时与系统文件/`：Word 临时文件、系统索引文件等不应参与主要阅读链路的材料。
- `AGENTS.md`：项目规则文件，保留在根目录，不参与归档移动。

## 放置规则

- 页面协议、业务状态、字段说明：放入 `02_产品方案与协议/`。
- 可直接演示或验收的 HTML：放入 `03_原型与页面/`。
- 截图、导出图、状态图、海报：放入 `04_设计稿与截图/`。
- 竞品、调研、访谈素材：放入 `05_调研与竞品/`。
- AI 协同方法、过程记录、培训材料：放入 `06_AI工作流与方法/`。
- 给管理层或阶段汇报用的内容：放入 `07_计划与汇报/`。
